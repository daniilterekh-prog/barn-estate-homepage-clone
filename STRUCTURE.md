# Структура страниц BARNES Moscow

Каждая production-страница хранится в отдельной папке с точкой входа `index.html` и своими стилями, скриптами и ассетами.

## Основной сайт

- `barnes-moscow/` — главная страница;
- `gorodskaya-nedvizhimost/` — городская недвижимость;
- `mezhdunarodnaya-nedvizhimost/` — зарубежная недвижимость;
- `zagorodnaya-nedvizhimost/` — загородная недвижимость;
- `kommercheskaya-nedvizhimost/` — коммерческая недвижимость;
- [`katalog-nedvizhimosti/`](katalog-nedvizhimosti/) — общая выдача: первым выбирается направление, затем меняются контекстные фильтры; полный header/menu/footer референса. Хэдер и карточки сверены с живым городским референсом; поиск над быстрыми фильтрами, подборки и сортировка под ними. Департамент — раскрывающийся список; desktop-фильтры в две строки. Публичное превью обновлено 21.10.2026.

- [`izbrannoe/`](izbrannoe/) — опубликованное избранное на UI-ките сайта; общий ключ сохранения с каталогом. [Пример подборки](https://daniilterekh-prog.github.io/barn-estate-homepage-clone/izbrannoe/?preview=1).

## Лендинги

- `arenda_sobstvennikam/` — лендинг аренды для собственников;
- `prodazha_sobstvennikam/` — лендинг продажи для собственников;
- `kurortnaya/` — лендинг курортной недвижимости.

## Специализированные страницы внутри сайта

- `stranitsa-zhk/` — страница ЖК «Вавилова 64».
- `stranitsa-lota/` — общий шаблон карточки лота. Данные 588036 служат демонстрационным наполнением, а не отдельным типом страницы. Вёрстка и поведение общие; данные объекта подставляются через `lot-data.js`.

Папки специализированных страниц обозначают **типы**, а не ID конкретных объектов. Для новых лотов используется тот же шаблон; меняются данные и изображения. Блоки ЖК, застройщика, строительства, карты и ипотеки показываются только при наличии соответствующих данных. Технические URL объектов в будущем задаются маршрутизацией/данными и не требуют копирования шаблона в новые папки.

Старые отдельные копии лотов `vtorichnaya-nedvizhimost/576683/` и `vtorichnaya-nedvizhimost/588036/` исключены из актуальной структуры. История сохранена в Git.

Старые HTML-адреса в корне оставлены как лёгкие перенаправления на новые папки.
Старый каталог `/vavilova-64/` также перенаправляет на `/stranitsa-zhk/`.
