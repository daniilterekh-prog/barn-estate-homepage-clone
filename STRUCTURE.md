# Структура текущего основного сайта

[Единый каталог13актуальных страниц](PAGES.md) · [Машинный реестр](CURRENT-PAGES.json). Рабочие исходники — в приватном barnes-sites, этот репозиторий хранит проверенный публичный экспорт.

Текущая главная: exact-2026-10-21/. Старые / и /barnes-moscow/ перенаправляют туда. Прежние HTML-входы сохраняют ссылки и query/hash, а не отдельные версии дизайна.

Узлы сохраняют собственные css/js/assets, переносимые блоки и шаблоны. Общие авторские компоненты собираются из main-site/shared/current-components.json; их копии не редактируются по одной. Перед экспортом применяется консервативное удаление CSS-дублей. Исторические варианты восстанавливаются из Git. Одобренные immutable tags не переписываются.

Самостоятельные библиотеки блоков и handoff-пакеты каталога/избранного сохранены; это текущие материалы для переноса, а не запасные версии страниц.

- `handoff/barn-club/` — один актуальный комплект HTML/CSS/JS/ассетов и ZIP для разработчика.
- `barn-estate-club/` — отдельная страница BARN Estate Club, экспорт из barnes-sites,09.11.2026.
