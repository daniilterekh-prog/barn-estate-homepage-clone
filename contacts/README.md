Свои CSS/JS, локальные Tilda Sans Light/Regular/Medium и SVG из согласованной библиотеки BARN Estate; лицензия Material Call в vendor/. Новых UI-библиотек нет. Внешняя зависимость — iframe Яндекс Карт. Пять финальных узлов и их общие ресурсы не изменяются.
