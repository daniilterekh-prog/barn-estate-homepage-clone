# Контакты BARN Estate

Новая самостоятельная страница `/contacts/` на утверждённом UI-ките главной **v1.0.3**. Вход: [index.html](index.html). Код страницы, изменяемые компоненты, шрифты и ассеты находятся в этой папке; защищённые пять узлов и их зависимости не изменяются.

Состав: компактный белый верх по «Избранному» без херо, три офиса с переключением, картами и маршрутами, способы связи внутри каждого офиса, контактный диалог и точная копия футера главной. Типографика, боковые поля, вертикальные интервалы и кнопки следуют UI-киту. Новые npm-пакеты и внешние UI-сервисы не подключены.

## Источники UI

- Ресурс: собственный утверждённый [UI-кит главной v1.0.3](../home/exact-2026-10-21/UI-KIT.md), проверен 09.11.2026.
- Хедер: `pages/media/media-header.css/js` и статическая разметка Media. Локальная копия в `vendor/`; изменены только навигационные адреса, единый телефон и подключение собственного контактного диалога. Меню, видимость контактов и размеры логотипа сохранены.
- Футер: `shared/node-footer/template.html`, `footer.css`, `logo.svg`. Локальный CSS ограничен `body.contacts-page`; телефон/график совпадают с основным содержимым страницы.
- Фото прежнего херо: `source/assets/home-office-estate.webp` утверждённой главной; [источник и история](../home/exact-2026-10-21/office-photo-2026-11-01/README.md). По новому поручению херо и локальная копия фото удалены из текущего пакета.
- Шрифты Tilda Sans Light/Regular/Medium и SVG мессенджеров скопированы из текущего комплекта Media. Логотип — канонический BARN Estate.
- Проверена frontend-памятка: строка HTML/CSS → HyperUI и строка иконок → Lucide. Принятые компоненты уже есть в проекте; сторонний компонент не заимствован, новых лицензионных зависимостей нет. Иконка Material Call в хедере сохраняет Apache-2.0 из исходного набора, см. `vendor/material-icons-LICENSE.txt`.
- Карты: официальный встраиваемый виджет Яндекс Карт по адресу, без сторонней библиотеки и без ключа API. В каждой карте есть самостоятельная ссылка на адрес и отдельный маршрут. Карты зависят от доступности Яндекса.

## Поведение и границы

- Офисы: `tablist`/`tab`/`tabpanel`, ArrowLeft/ArrowRight/Home/End, корректный фокус и `aria-selected`. Без JS адреса и маршруты всех трёх офисов доступны; вспомогательные карты не обязательны для связи.
- Контактный диалог: native `dialog`, Escape и возврат фокуса; ссылки на телефон, почту и существующие мессенджеры. Формы, CRM и отправка заявок не подключены; ложного сообщения об отправке нет.
- Мобильное меню: Escape, ограничение фокуса, основной контент `inert` при открытом меню.
- `prefers-reduced-motion`, видимый фокус, skip link, один H1. Статическое превью закрыто от индексации `noindex,nofollow`; установка на основной домен не выполняется этой задачей.
