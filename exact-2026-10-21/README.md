Основа — https://barn-estate.ru/, снимок 21.10.2026. 27.10.2026 поверх снимка подключён `home-typography.css`: текст приведён к каноническому UI-киту собственников и амбассадоров. Это адаптация снимка, а не текущая копия оригинала 1:1. Сохранены оригинальные HTML, CSS, шрифты, изображения, hero-видео и клиентская Nuxt-сборка. Версия подготовлена для GitHub Pages: пути учитывают подпапку, начальные GET-данные фильтра воспроизводятся из снимка. Меню, фильтры и окно обращения используют оригинальный клиентский код.

Это визуальное превью главной. Другие страницы и живой серверный поиск не перенесены; отправка заявок отключена. Видео отзыва загружается с исходного сайта. Превью закрыто от индексации через `noindex,nofollow`.

Каноническая рабочая версия, экспорт `tools/export-pages.cjs` и полные проверки хранятся в `barnes-sites/main-site/pages/home/exact-2026-10-21/`. Здесь находится только публичная сборка. Авторские права и уведомления исходного сайта сохраняются.

Для отката достаточно отменить commit публикации: прежние страницы репозитория этим экспортом не заменялись.
