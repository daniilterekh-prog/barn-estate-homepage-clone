# Хедер

## Что вставить

- Одним фрагментом: [paste.html](paste.html) целиком.
- Раздельно: block.html + block.css + block.js + assets/.
- Проверить: [index.html](index.html).

## Поведение

Бургер, меню, липкое состояние при прокрутке, выбор четырёх способов связи на мобильном; SVG звонка зелёный.

## Подключение

[Инструкция по переносу](https://github.com/daniilterekh-prog/barnes-sites/blob/main/main-site/pages/home/exact-2026-10-21/INSTALL.md) · [UI-кит](https://github.com/daniilterekh-prog/barnes-sites/blob/main/main-site/pages/home/exact-2026-10-21/UI-KIT.md). Сохранить классы, data-v/data-атрибуты, ARIA и JSON. Тексты и ссылки — content.json, параметры — design.json, источники ассетов и лицензии — manifest.json и assets/.
