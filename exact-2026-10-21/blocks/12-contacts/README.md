## Что копировать

[ZIP этого блока](../downloads/12-contacts.zip) · [Скачать всю библиотеку](../downloads/homepage-blocks.zip).

Быстрая вставка: [paste.html](paste.html) содержит стили, скрипт, изображения и шрифты внутри одного HTML-фрагмента. Его можно целиком вставить в HTML-блок сайта. Для раздельных файлов скопируй папку целиком. `index.html` — готовое автономное превью; `block.html` — фрагмент для вставки; `block.css` — изолированные стили; `block.js` — обработчики; `assets/` — все необходимые изображения, шрифты и лицензия. Для вставки подключи CSS и JS, затем вставь block.html. Относительные пути assets/ должны оставаться доступными относительно HTML; при переносе в подпапку обнови src/srcset/URL в HTML и JSON-состояниях. CSS-url считаются относительно block.css.

```html
<link rel="stylesheet" href="/blocks/12-contacts/block.css">
<!-- содержимое block.html, assets/ переписаны на /blocks/12-contacts/assets/ -->
<script defer src="/blocks/12-contacts/block.js"></script>
```

## Поведение и интеграция

Контактная бровь и заголовок, ссылки на email/маршрут/мессенджеры/звонок. Фото офиса с новым логотипом, без водяного знака, нижняя граница по левому контенту; телефон без фото.

Квиз включён в runtime и открывается штатными кнопками «Оставить заявку», «Обратная связь», плавающим экспертом либо элементом data-barn-quiz. В нём три вопроса и контакты, ветка партнёрства, Руслан с журналом, три валюты ₽/$/€, постоянная высота окна, валидация, Escape и удержание фокуса. Обработчики заявок и подписки требуют подключения сайта; без него явно показывается «Данные не отправлены».

Для отправки слушай события `barn:lead` (detail.data/form/status) и `barn:subscribe` (detail.email/consent/form); вызови preventDefault(), отправь данные своему серверу и обнови статус после подтверждённого ответа. Поиск вызывает `barn:search` (query/deal/category/filters), который должен обработать каталог принимающего сайта. По умолчанию показана ссылка на каталог BARN Estate без заявления о применении фильтров. Секретов и URL CRM в пакете нет. Ссылки навигации ведут на barn-estate.ru; для своего сайта замени их по карте content.json.

Изоляция CSS защищает окружающую страницу. Пакет использует Tilda Sans и исходные SVG. Splide core взят из уже используемой сборки главной, Vue-обёртка удалена; MIT-лицензия в assets/SPLIDE-LICENSE.txt. Внешний видеоролик (только видеоблок) остаётся по исходному URL; все изображения локальны.
