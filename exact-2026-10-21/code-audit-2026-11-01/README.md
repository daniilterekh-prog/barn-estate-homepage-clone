# Аудит кода актуальной главной — 01.11.2026

Проверены подключаемые home-*.css/js, локальная выдача и статический экспорт, шесть категорий рекомендаций, изображения, ссылки, меню, раскрытие текста, избранное и квиз. Проверка не включает отправку реальных заявок, подписок или переход по каждой внешней странице.

## Исправлено

- Удалены неиспользуемый массив старых характеристик лотов, функции fact/known/arrow, вычисление площади и обработчик отсутствующей кнопки звонка. Скрипт рекомендаций: 15 572 → 6 166 байт (−60%). Сохранённые исторические данные в recommendations-review/data.json остаются справочным материалом, генератор больше не вставляет их в исполняемый JS.
- Удалены стили отсутствующих delivery/image-error элементов и отменённые настройки стрелок. Их итоговое расположение справа сохранено, без повторного переопределения. CSS рекомендаций: 11 763 → 10 929 байт.
- В загородных рекомендациях устранён запрос изображения с 404: исходная картинка недоступна, используется явно обозначенная нейтральная заглушка. У коммерческого объекта без фото теперь создаётся текущая карточка вместо скрытого старого представления. Чужие фотографии объектов не использованы.
- Исправлены ссылки первых двух направлений: «Новостройки Москвы» → https://barn-estate.ru/novostroyki/, «Вторичная недвижимость» → https://barn-estate.ru/vtorichnaya-nedvizhimost/. Адреса взяты из действующего меню самой страницы. Прежде второй пункт вёл в загородную недвижимость.
- Относительные ссылки направлений, экспертов и политики переводятся на исходный barn-estate.ru; сохранённый Vue router не перехватывает эти переходы. Иначе GitHub Pages искал несуществующие страницы на домене превью.
- Добавлен общий список активных дополнительных ассетов tools/home-assets.cjs для сервера и экспорта. Девять прежних вариантов изображений удалены из публичной папки и больше не копируются экспортом. В рабочем архиве они сохранены как история, но не подключены к странице.
- Изменения синхронизированы в блоках 04/05, HTML-вставках, манифестах, снимке генератора и ZIP.

## Что остаётся и почему

Исходная скомпилированная Nuxt-сборка и HTML-снимок — основа этой копии: из них работают фильтры, карусели, меню и данные. В них есть исходные компоненты/стили, часть которых перекрывается нашими адаптациями. Удалять их по одному признаку «не использовалось при загрузке» опасно: они могут понадобиться в другом состоянии. Это не полная пересборка сайта с нуля и не доказательство отсутствия каждого неисполняемого байта в исходном vendor-коде.

GitHub Pages — статическое превью. Отправка заявок/рассылки и произвольные запросы к серверному каталогу не подключены; это известное ограничение копии, а не исправленная в этом аудите интеграция. Рабочие страницы каталога открываются на оригинальном сайте. В курортной категории сохранённого источника объектов нет — пустое состояние сохранено.

Дополнительно: visual-regression.json — девять растровых сравнений услуг, рекомендаций и направлений на 390/1440/2560px; отличающихся пикселей при пороге 0.1 нет. Для сравнения подставлялись CSS/JS до очистки из Git, геометрия и оформление не изменились. export-checks.json — те же основные сценарии на готовом статическом экспорте, четыре ширины, без замечаний. Во время браузерных проверок MP4-потоки отключены; воспроизведение внешнего видео и доступность каждого внешнего URL в этот аудит не входят.
