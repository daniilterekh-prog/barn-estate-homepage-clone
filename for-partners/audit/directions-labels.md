# Подписи и порядок показателей направлений — 2026-10-08

## Причина

В directions.js бюджет и комиссия использовали порядок «подпись, значение», а metrics — «значение, подпись». Исправлен рендер всех числовых metrics на «подпись, значение». Текстовые facts уже имели этот порядок.

## Типографика

Large card description из reference-ui.md: Tilda Sans22/28.16px,300 для подписей бюджета, metrics, комиссии, примечаний, единиц измерения и текстовых значений. До1024px используется Body16/22.4px,300. Числовые значения, заголовки, навигация и кнопка не изменены. Исходные цифры и условия сохранены.

Для синхронного выравнивания цифр резерв подписей metrics: две строки56.32px на десктопе; три строки67.2px до1024. Интервал до значения12px. Высота средней строки и размеры фото сохранены.

## Проверка реальной страницы

Все7 категорий переключены через вкладки Enter на десктопе и selectOption на мобильном. Ширины320/390/1024/1025/1440/1920.

- Computed desktop labels22px/300, mobile16px/300.
- Первым дочерним элементом каждого metrics является bd-label.
- Числа в двух колонках на одной Y-координате (допуск1px).
- Высота панели и Y кнопки неизменны между категориями:968px на320/390,662px на1024/1025/1440/1920.
- На двухколоночном десктопе низ фотографии совпадает с низом кнопки (допуск1px); на мобильном фотография отдельной строкой.
- Ни один дочерний блок bd-copy не обрезает текст по высоте.
- Временный viewport сброшен. Локальный сервер4183 восстановлен после остановки предыдущего процесса; финальный тест проведён в отдельной временной вкладке, затем закрытой.
