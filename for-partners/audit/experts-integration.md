# Проверка блока «Ваш клиент в руках экспертов»

Дата: 2026-10-08. Исходный пакет: BARNES_Experts_Codex.zip.

Вариант: рекомендуемый `barnes-experts--open`, без переключателя вариантов. Позиция: сразу после `.ambassadors-advantages`, перед `.catalog-contact`. Материалы для партнёров пока не внедрены. Перенесены четыре пункта и исходные формулировки без новых обещаний.

## Проверки

- Разрешения: 320, 375, 390, 540, 768, 1024, 1280, 1440, 1920 px.
- Фактически загруженная Tilda Sans, H2 300, H3 400, Body 300, Eyebrow 400. Размеры: H2 22/38/44, H3 18/20/22, Body 16/22.4, Eyebrow 12/14 — по breakpoint-контракту архива и ТЗ.
- Один H1 страницы; новая секция H2, четыре H3 и семантический список. Доступное имя секции через aria-labelledby.
- Desktop: две колонки; до 1024 px: заголовок над списком, gap 32 px. Высота по содержимому. Локальные разделители и маркеры сохранены.
- Общие направляющие с блоком преимуществ; нет горизонтального переполнения страницы/секции, пересечений с соседями или наложения заголовков пунктов на описания.
- Внешние отступы исходного компонента: 80 px desktop, 48 px tablet, 36 px mobile. Вложенный контейнер не добавляет вертикальные отступы. На 1440 px предыдущая секция заканчивается ровно перед новой, контактная начинается после неё.
- Все семь направлений переключаются на 390 и 1440 px; активный таб и заголовок панели синхронны. Файлы направления, фотографии, комиссия, CTA и обработчик существующей формы не изменены.
- Ошибок JavaScript при загрузке нет. Остальная разметка сохранена: в index.html добавлены только секция и stylesheet; метаданные, hero, шапки, форма, FAQ, футер не редактировались.
- Визуально сверены исходный preview.html (открытый список), desktop 1440 px и mobile 390 px. Разница ширины — штатный контейнер сайта вместо автономного preview-контейнера.

Машинные результаты: `experts-checks.json`. Скриншоты: `experts-{width}.png`. Для ускорения теста изображения других блоков не загружались; данный блок изображений не содержит. На скриншотах скрыта существующая плавающая карточка эксперта тестовым CSS, не изменяющим сайт.

Повторить: запустить HTTP-сервер корня репозитория на 4183, затем `node for-partners/audit/check-experts.cjs` с доступным пакетом Playwright. BASE_URL и CHROME_PATH можно переопределить окружением. Скриншоты и JSON генерируются сценарием.

## До публикации

Код сохранён в отдельной ветке GitHub; master и публичная страница не обновляются по прямому ограничению CODEX_PROMPT.txt. Требуется подтверждение всех предложенных текстов об услугах, перечисленных в разделе 7 implementation-spec.md, и отдельное поручение на публикацию.
