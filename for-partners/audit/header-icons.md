# Иконки шапки — 2026-10-08

Причина локального сбоя: sparse-checkout содержал только for-partners, а верхняя и закреплённая шапки используют общие pictures/office-contact/{whatsapp,max,telegram}.svg. Реальный HTTP-сервер возвращал404. Файлы присутствуют в GitHub, пути страницы корректны, заменять дизайн и дублировать ассеты не требуется.

В рабочую копию добавлен минимальный каталог командой `git sparse-checkout add pictures/office-contact`. Для будущей выборочной рабочей копии необходимо включать оба каталога: for-partners и pictures/office-contact. Это зависимость страницы, а не потерянные файлы в репозитории.

Регрессионная проверка check-header-icons.cjs проверяет реальные HTTP200, SVG MIME и успешное декодирование трёх иконок в каждой шапке на1440/390 px. Эти запросы не подменяются файловыми ответами. Остальные фотографии отключаются только в тесте для снижения нагрузки браузера. CSS, тексты, ссылки, SEO-метаданные не менялись.

Прогон390 px прошёл на полной странице. На1440 px полный документ аварийно завершал Chromium; проверка выполнена в FOCUSED=1 с исходной шапкой и настоящим for-partners.js, создающим контакты обеих шапок. Общие SVG в обоих режимах загружаются настоящими HTTP-запросами. Скриншот1440 — focused headers, не полная страница.
