# Интеграция утверждённого блока «Направления BARNES»

Дата: 8 октября 2026.

## Дополнение из презентации и сверка UI-кита

По последующему запросу заказчика добавлены подробности всех семи направлений. Для Подмосковья раскрыты шоссе и типы объектов; для зарубежной недвижимости — закрытые предложения, резидентская виза ОАЭ, паспортная программа Турции и работа через европейскую сеть; для коммерческого направления — аренда, подбор помещений, ГАБ и консультации по стоимости/ставкам. Цены и ставки не изменены. «Менее 7 лет» подписано как расчётная окупаемость.

Подробности размещены ниже фиксированной композиции в одинаковой для всех категорий сетке. Фото остаётся 550/290 px, основная текстовая колонка — 550 px. Новые данные не сдвигают CTA при переключении. На desktop сетка подробностей 2×2, на mobile — четыре строки с одинаковой резервируемой высотой.

Локальные исключения H2/eyebrow/CTA исходного handoff отменены по новому запросу заказчика: H2 теперь 38/44/22 px, weight 300; eyebrow 14/12 px, weight 400; CTA 70/58 px, labels 17/19/18 px, weight 400. Названия направлений используют H3 22/20 px, weight 400, основной текст Body 16/22.4 px, weight 300; metadata 13/18 px, weight 400. Вкладки увеличены с 15 до 17 px. Числовые показатели усилены до 38 px Light; комиссия сохраняет согласованный акцент 48 px Regular. ВНЖ/коммерция сохраняют подпись об индивидуальном согласовании комиссии.

Новый полный прогон ui-kit-results.json: 84 сценария без ошибок, без изменения геометрии при переключении. Дополнительный мобильный прогон после уменьшения пустых интервалов в подробностях: ui-mobile-results.json. Снимки направлений обновлены. Прежние параметры ниже описывают исходную интеграцию; актуальные значения перечислены в этом дополнении.

Источник: BARNES_Directions_Codex.zip, CODEX_TASK.md, README.md, ASSETS.md, reference.html. Визуальный эталон открыт и сравнен с интеграцией. Демонстрационная шапка и переключатель размеров не перенесены.

## Реализация

- Секция #requests заменена встроенным HTML-компонентом: категории сверху, фото слева, описание справа. Сохранён якорь sticky-навигации.
- Переиспользованы Tilda Sans из проекта и внешний base-container, без двойных горизонтальных полей. На широких экранах внешний контейнер сайта имеет приоритет над автономным ограничением 1320 px.
- Сохранена сетка 1.3:1, интервалы 48/28 px, высота фото 550/290 px и текстовой колонки 550 px.
- Слоты заголовка, описания, бюджета, показателей и комиссии имеют явные одинаковые высоты для всех категорий. Комиссия 48/48 px выделена бордовым. Категории без процента сохраняют «Формат»/«Инвестиции».
- Согласованные H2 38/28 px, подписи 11/10 px и CTA 56 px являются локальными исключениями секции. Остальные кнопки и заголовки страницы не изменены.
- Удалены прежний обработчик requests и подключение его устаревших типографических стилей.

## Форма

Событие barnes:request открывает существующее modal-окно и передаёт directionId и directionName в скрытые поля существующей формы. Название выбранного направления видно над полями. При открытии через другую CTA предыдущий выбор очищается. Сохранены поля, согласие, валидация и существующий обработчик submit. Новые CRM/API/аналитические сервисы не добавлены.

Ограничение существующей формы: её обработчик показывает локальное сообщение успеха, сетевой доставки заявок нет. В рамках этой задачи проверены открытие и состояние формы, а не доставка в CRM. Реальные заявки при проверке не отправлялись.

## Данные и изображения

Дополнение: у категорий «ВНЖ и гражданство» и «Коммерческая недвижимость» добавлена подпись «Комиссия: условия оговариваются». Презентация не задаёт отдельных универсальных ставок для этих категорий. Исходные строки «Формат — С недвижимостью» и «Инвестиции — ГАБ» сохранены. Подпись размещена внутри существующего фиксированного слота 68 px. Проверены семь категорий на 320, 390 и 1280 px: высота колонки и положение CTA неизменны, подпись помещается.

Коммерческие значения совпадают с текущими данными страницы: 52 млн ₽, 50 млн ₽, 250 тыс. ₽, 200 тыс. $, комиссии 3–5%, 4–5%, 50–100%, 2–5%; для ВНЖ и коммерческого направления проценты не добавлены. Согласованные тексты и форматирование взяты из handoff. Расхождений в числовых условиях нет.

Использованы семь WebP из пакета. Москва — реальная фотография, остальные шесть — исходные одноцветные заглушки. Проверен каталог канонического barnes-assets: новых изображений для этого блока не найдено. Случайные замены не сделаны.
