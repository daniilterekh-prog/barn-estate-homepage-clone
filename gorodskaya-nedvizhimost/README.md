# Городская недвижимость — узел первой степени

## RequestModal из Курортной

`node-modal.js` переносит разметку и обработчики `enhanceContactModal` из `../kurortnaya/ui-kit-runtime.js`; оформление уже находится в `node-ui.css`. Источник: [Курортная / ui-kit-runtime.js](https://github.com/daniilterekh-prog/barn-estate-homepage-clone/blob/master/kurortnaya/ui-kit-runtime.js), 12 октября 2026. Портрет адаптирован под Руслана; остальные страницы и исходный runtime Курортной не менялись.

Окно открывается через «Оставить заявку», «Заказать звонок» на карточках и плавающую карточку эксперта. Перехват выполняется до обработчиков Nuxt, поэтому старый modal не открывается одновременно. Сохранены каналы связи, подписи полей, обязательное согласие, Escape, замыкание Tab и возврат фокуса. Сброс формы восстанавливает подпись Telegram. Как и в референсе, сервер отправки не подключён; после проверки полей явно сообщается, что демонстрационная заявка не отправлена.

Проверка: `scripts/verify-city-modal.cjs` (Playwright из существующего web-capture-toolkit). На ширинах 390, 768, 1366, 1920, 2560 px геометрия окна, формы и заголовка точно совпала с референсом. Проверены открытие из карточки/плавающего эксперта/desktop-header, каналы, валидация, согласие, Tab, Escape, возврат фокуса, отсутствие второго Nuxt modal, overflow и pageerror. Новые библиотеки не добавлены.

Единая фотография покрывает весь desktop CTA вместо отдельного интерьерного фона и половины фотографии. Мобильный аватар и форма сохранены. Новые библиотеки не добавлены. В одноколоночной tablet-компоновке используется правая часть того же интерьера с затемнением. Исходные фотографии и остальные страницы не изменены.

## Реализация и проверка

Брови, типографика, размеры кнопок, фильтры с нижними линиями, LaunchCard и ListingCard соответствуют контракту первого уровня. Лоты используют исходные площадь/спальни/этаж и ID справа от цены. Режим проектов содержит реальные ЖК из блока стартов продаж. Неизвестные сроки/спальни обозначены «По запросу».

Фильтры работают по загруженному набору: локация, верхняя цена, минимальное количество спален. Полные фильтры открывают исходную форму Nuxt. Новые формы заявок и новые API не добавляются.

Обновление snapshot: `python3 scripts/sync-city-real-estate.py`; только применение дизайна: `--design-only`. Проверять через HTTP, в том числе по вложенному пути GitHub Pages. Основные ширины проверки: 390, 768, 1366, 1920, 2560 px.

Проверка 12 октября 2026: на всех пяти ширинах нет горизонтального overflow и pageerror. Hero H1: 32/33.6 mobile, 54.64/57.372 на 1366, 58/60.9 wide. H2 каталога: 22/26.4, 38/45.6, 44/52.8 соответственно. LaunchCard: высота 438 px; секция стартов и её header совпадают с референсом на 390 и 1366. Совпадают ширина и пропорции медиа карточки, toolbar, шрифты названия/цены/фактов. Проверены переключение режимов, фильтрация, полный фильтр и сохранение оформления после его применения. Контентные высоты зависят от количества городских объектов и длины текстов.
