# Городская недвижимость — узел первой степени

## Синхронизация референса 12 октября 2026

Источник UI: [Курортная, состояние 9b83c5d / сводка f0b0e46](https://github.com/daniilterekh-prog/barn-estate-homepage-clone/blob/master/kurortnaya/changes-2026-10-12.md). Канонический [FirstDegreeNode в barnes-assets](https://github.com/daniilterekh-prog/barnes-assets/blob/main/ui-kit/first-degree.md), синхронизация 12.10.2026. Новые библиотеки, API-ключи и пакеты не добавлены. Использованы существующие авторские компоненты проекта, сохранены источники изображений.

Перенесены четыре равных быстрых фильтра «Локация / Тип / Стоимость / Спальни», единый белый popover параметров и сортировки в листинге/карте, галочки выбранных пунктов, бордовые состояния и отсутствие теней. Desktop — четыре поля в ряд, tablet/mobile — 2×2. Типографика, SVG, chevron и отступы происходят из актуального UI-кита.

Рынок обязателен: ровно один new-build/secondary, по умолчанию new-build. Карта и листинг синхронизируются через BarnesFilters; повторное нажатие и reset не снимают выбор. Два независимых чекбокса «Выбор BARNES» / «Эксклюзив BARNES» синхронизированы. Порядок карты: параметры → сортировка → чекбоксы → сброс, шаг рядов 70px. На mobile квадраты чекбоксов совпадают с колонками SVG. Сортировка использует тот же popover, скрытый select — только адаптер значения.

Общий подробный фильтр: тёмное центральное окно из херо, листинга и кнопки над картой; белая правая панель из полноэкранной карты (mobile — весь экран). Московские районы, исходные характеристики и городские ссылки сохранены. Применение не запускает Nuxt-навигацию на другой маршрут. Escape отменяет черновик; apply/reset сохраняют обязательный рынок. Проверяются диапазоны, клавиатура, inert фона и возврат фокуса. Закрытие вложенного окна оставляет карту открытой.

Обновлены футер собственников-продажи со ссылкой «Амбассадоры», обратная связь через общую форму, мобильная кнопка заявки рядом с контактами, центрирование телефона/логотипа/меню в hero. В CTA методы связи имеют общие края с формой, max-width610px, одинаковые внутренние колонки SVG/текста. Адрес расположен над названием и в ЖК, и в лотах; характеристики лота — локация/площадь/спальни, ID справа от цены.

### Границы локальных данных

Сохранены реальные московские названия, изображения, цены, ссылки и контент. Проекты листинга — четыре ЖК из городских стартов; лоты — исходный адаптивный снимок. Локация, ценовые диапазоны и спальни листинга фильтруют доступные данные. Для типов помещений, брендовых подборок, районов и дополнительных характеристик полных метаданных нет: выбор хранится в UI, но боевую API-фильтрацию не имитирует. Признаки эксклюзивности и недостающие характеристики не выдумываются.

Карта использует фиксированный снимок16 объектов:4 ЖК (new-build) +12 лотов (secondary). Это разделение сохранённых поисковых веток, не новая оценка строительного статуса объектов. Поиск по названию, верхняя цена, сортировка и reset работают локально. Параметры без метаданных сопровождаются пояснением как в референсе; брендовые чекбоксы — только UI до подключения данных. Неизвестная цена не проходит ограничение цены. Контролы +/− масштабируют статичное изображение, не географическую карту. Маркеры не пересчитываются; атрибуция Яндекс и видимая пометка сохранены. API карты/каталога не подключён.

### Файлы и происхождение

- node-ui.css / node-listing.css / node-launch.css — актуальные соответствующие стили Курортной; node-city.css — только городские исключения.
- quick-filters.js/css, brand-filters.js/css, filters-modal.js/css — контроллеры референса с московским адаптером.
- filters-template.js — разметка исходных городских фильтров с именами полей; filters-source.css — только правила фильтров из актуального source.css Курортной, приведённые к её CSS scope. Не подключать весь курортный runtime на городской.
- city-map-fullscreen.js/css — актуальная оболочка Курортной; city-map-projects.js / assets/city-map-preview.png — отдельные московские данные и подложка.
- footer-template.js / owner-footer.css — актуальная разметка и стили футера референса; city-reference-extras.js адаптирует только общие элементы.
- node-reference.js — городской адаптер после завершения Nuxt hydration; не меняет главную/Курортную/будущие узлы.
- node-modal.js — RequestModal Курортной с собственным городским портретом. Отправки в CRM нет: демонстрационная форма честно сообщает, что заявка не отправлена.
