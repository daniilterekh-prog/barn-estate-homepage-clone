# start-sales

Городской компонент, экспортированный из текущей страницы. fragment.html / mobile.html — итоговый DOM; page-desktop.html / page-mobile.html (если есть) — источник сборки целой страницы. Не применять адаптер повторно к итоговому DOM. Ассеты и CSS находятся внутри этого узла; для переноса сохранить структуру. Боевые формы и данные подключаются хостом.
