# Проверки автономного пакета

- `cleanup.json`:264 явно удалённых файла,48 985 826байт. Восстановление через Git.
- `baseline.json`: первичный снимок до миграции с ещё не загруженными ленивыми изображениями. Не settled pixel-diff.
- `design-parity.json`: сравнение геометрии 9 ключевых блоков и типографики с прежней опубликованной городской страницей после загрузки изображений/шрифтов на 9 ширинах 320–2560px. Не побитовое сравнение скриншотов.
- `package.json`: самостоятельная страница на9 ширинах320–2560px и21 превью на mobile/desktop,51 сценарий. Проверяются изображения, overflow, ошибки JS/HTTP, внешние запросы ресурсов, меню, FAQ, карта, рынок, фильтры и форма.

Проверки требуют Playwright и Chrome. `PLAYWRIGHT_PATH` указывает уже установленный runtime, без зависимостей страницы. `scripts/verify-city-reference-sync.cjs` и `verify-city-listing-titles.cjs` поддерживают `CITY_BASE_URL`.

Статичная карта, сохранённые данные, демонстрационные формы. Полный аудит WCAG и живой backend не входят в упаковку.
