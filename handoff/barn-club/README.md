# BARN Estate Club — пакет для разработчика

Одна актуальная версия, 10.11.2026. [Скачать ZIP](barn-club.zip) · [Полная страница](html/index.html) · [Опубликованная страница клуба](https://daniilterekh-prog.github.io/barn-estate-homepage-clone/barn-estate-club/?v=h2-uppercase-20261110).

## Что передать

Передай всю папку или `barn-club.zip`. После распаковки открой `barn-club/html/index.html` через локальный HTTP-сервер. Например, из папки `barn-club`: `python3 -m http.server 8000`, адрес `http://localhost:8000/html/`. Сборка, npm и внешние библиотеки сайту не нужны. Шрифты и все отображаемые изображения локальные.

| Путь | Назначение |
| --- | --- |
| `html/index.html` | Полная самостоятельная HTML-страница с head/body и подключениями |
| `html/01-header.html` | HTML-фрагмент: хедер, меню, контакты, крошки |
| `html/02-main.html` | HTML-фрагмент: весь основной контент и форма |
| `html/03-footer.html` | HTML-фрагмент: футер |
| `css/footer.css`, `css/club.css` | Стили; подключать именно в этом порядке |
| `js/club.js` | Меню, контакты, sticky-хедер, крошки, валидация и email-черновик |
| `assets/` | Только 12 используемых изображений, SVG и шрифтов |
| `data/sources.json` | Происхождение текущих изображений, хэши и описание обработки |
| `DESIGN.md` | Размеры, цвета, адаптив и поведение |
| `SOURCE.json` | Канонический источник и контрольные суммы runtime-файлов |
| `VERIFICATION.json`, `CHECKSUMS.sha256` | Результат проверки и целостность комплекта |

Фрагменты не являются самостоятельными страницами. Они выделены из полной страницы и собираются в порядке 01 → 02 → 03 внутри `<body id="top">`. Подключения из `<head>` бери из `html/index.html`. Не вставляй одновременно полную страницу и фрагменты. Пути `../assets/`, `../css/`, `../js/` рассчитаны на папку `html/`; при встраивании в шаблон замени префикс на реальный URL каталога один раз. Стили содержат правила уровня документа (`body`, `h2`, `.container`); согласуй их с шаблоном сайта, подключай один раз. Существующие классы/ID нужны скрипту. Не запускай `club.js` повторно и не меняй ID полей/якорей без правки скрипта.

## Форма и публикация на домене

Имя, email и согласие обязательны; телефон необязателен. Текущая кнопка готовит редактируемое письмо на `moscow@barn-estate.com` через `mailto:`. Посетитель отправляет его в почтовом приложении сам. Показан честный статус и запасная ссылка. Серверной отправки, CRM, аналитики и хранения заявки нет. Для боевого сайта подключи штатный обработчик, настрой сообщения об успехе/ошибке и защиту от повторной отправки; до этого не подменяй статус на «Отправлено».

В превью оставлен `noindex, nofollow`; при публикации на боевом домене проверь robots, canonical и OG URL. Canonical сейчас `https://barn-estate.ru/barn-estate-club/`. Навигация ведёт на существующие разделы barn-estate.ru, поиск — на публичное превью каталога: замени его на боевой маршрут. Телефоны, почта, мессенджеры и маршрут — внешние ссылки; тесты сообщения не отправляли. Боевой домен этим пакетом не обновлён.

## Источник и обновление

Канонический исходник: [barnes-sites/main-site/pages/barn-club](https://github.com/daniilterekh-prog/barnes-sites/tree/main/main-site/pages/barn-club). Канонический готовый пакет: `barnes-sites/main-site/handoff/barn-club/`. Публичный экспорт: [handoff/barn-club](https://github.com/daniilterekh-prog/barn-estate-homepage-clone/tree/master/handoff/barn-club). Редактировать исходник, затем обновлять эту же папку и ZIP. История предыдущих вариантов — в Git.

Основа — утверждённый UI-кит BARN Estate v1.0.3, изолированные копии хедера/футера из согласованного комплекта амбассадоров; херо сверено с текущей «Медиа». Новых библиотек и платных компонентов нет. Фотографии с исходной страницы клуба, главной и выбранные владельцем фото с Диска. Иллюстрация особняка с зелёной машиной — сгенерированная, происхождение и точный промпт закреплены в `data/sources.json`. Оригиналы всей подборки Диска остаются в приватных исходниках; в комплекте только выбранные изображения. Tilda Sans 300/400 — шрифты существующего сайта.

Проверки и повторная сборка для сопровождающего — в `tools/` GitHub-папки; ZIP содержит только готовый комплект и документацию. `build.py` запускается из checkout barnes-sites после обновления исходника. `verify.cjs` использует установленный Playwright Toolkit (переменная `CODEX_TOOLKIT_DIR`), сам сайт от него не зависит.
