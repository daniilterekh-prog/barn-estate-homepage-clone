# Данные и интеграции

## Каталог

Текущая загрузка — `fetch('objects.json')` в `listing.js`. Формат ответа: массив объектов, без оболочки `{items: ...}`. В пакете 37 сохранённых записей: Москва 7, Загородная 6, Коммерческая 4, Курортная 12, Зарубежная 8. Арендные записи есть только в коммерческой; пустые результаты других сочетаний не подменяются вымышленными объектами.

| Поле | Смысл |
| --- | --- |
| `id` | Стабильная строка, в том числе числовой ID строкой |
| `title`, `url`, `image`, `address` | Название, ссылка объекта, изображение и адрес |
| `direction`, `deal` | Департамент из BEHAVIOR.md, `buy` / `rent` |
| `kind` | `project` / `lot`, выбор шаблона карточки |
| `market` | `new-build` / `secondary` там, где рынок применим |
| `price`, `priceLabel`, `currency` | Число либо null; готовая подпись; в текущих записях RUB. Арендная цена — в месяц |
| `area`, `landArea`, `rooms`, `bedroomCount` | Числа либо null/отсутствие, если неизвестны; `landArea` предусмотрено фильтром, в текущих сохранённых данных может отсутствовать |
| `directions` | Массив конкретных локаций, не департаментов |
| `propertyTypes` | Ключи типов из `BarnesCatalogTypes` в `direction-profiles.js` |
| `brandFlags` | Массив `selection` / `exclusive` |
| `stats` | Массив пар `[значение, подпись]` для карточек лотов |
| `completion`, `bedrooms`, `locationLabel` | Готовые подписи проекта |

Остальные сохранённые поля (`location`, `category`, `distance`, `type`, `exclusive`) сохраняют происхождение данных; отображение и фильтрация опираются на перечисленные нормализованные поля. Числовые данные не следует извлекать из форматированных подписей на стороне API.

Вариант внедрения: заменить URL загрузки на endpoint с тем же массивом. Если поиск/фильтры/пагинация переезжают на сервер, заменить соответствующую логику `listing.js` и обеспечить единый полный результат/total для карты и счётчика, сохранение URL и одинаковую сортировку.

### Текущие интерфейсы клиента

`window.BarnesFilters.getState()` возвращает копию применённых полей; `.patch(fields)` применяет изменения. Событие `barnes:filters-apply` публикуется после применения. `barnes:filters-open` используется адаптером контекста/закрытием dropdown, не следует использовать его как сигнал успешного применения.

`window.BarnesCatalogListing.getSnapshot()` возвращает `{items,ready,error,direction,query,sort,onlyFavorites,filters}`. `items` — вся текущая выдача до пагинации. Событие `barn:catalog-results` содержит этот снимок в `event.detail`.

Другие методы: `setQuery(value)`, `setDirection(key)`, `setMarket(value)`, `setMode(0|1)` (покупка/аренда), `setSort(value)`, `reset()`.

## CRM и заявки

Квиз и формы вызывают **всплывающее отменяемое событие `barn:lead`**. В `event.detail` находятся:

- `data` — значения `FormData`; `quizAnswers` передаётся JSON-строкой;
- `form` — форма;
- `status` — элемент для статуса.

Адаптер добавляет `pageUrl` и `department`. Заявка из карточки содержит контекст объекта, включая ID/название; состав смотреть по реальному `data`, а обязательные поля валидировать сервером.

Без перехвата форма показывает «В превью отправка заявок не подключена. Данные не отправлены». Для интеграции вызвать `event.preventDefault()` синхронно, отправить данные в существующий backend и показать подтверждение только после его успешного ответа. При ошибке оставить введённые значения и вывести доступный статус. Защиту от повторной отправки, серверную валидацию, антиспам и принятие согласия реализовать в штатной системе сайта.

```js
// Пример места подключения. URL заменить на настоящий маршрут сайта.
document.addEventListener('barn:lead', async (event) => {
  event.preventDefault();
  const { data, status } = event.detail;
  status.textContent = 'Отправляем…';
  try {
    const response = await fetch('/api/leads', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data)
    });
    if (!response.ok) throw new Error('lead request failed');
    status.textContent = 'Заявка отправлена.';
  } catch {
    status.textContent = 'Не удалось отправить. Попробуйте ещё раз.';
  }
});
```

В этом пакете обработчик выше не установлен, реальных отправок нет. Не класть ключи CRM в клиентский JavaScript.

## Карта

`catalog-map.js` использует общий снимок выдачи, включает весь отфильтрованный список, крестик, zoom и мобильную шторку. Фон `map-view/map-preview.png` — статичный снимок OpenStreetMap; zoom масштабирует изображение. Подтверждённых координат в данных нет, маркеры объектов не выдуманы.

Для живой карты подключить выбранный SDK/провайдер, координаты из backend, маркеры/кластеризацию и синхронизацию выбранной карточки. Сохранить текущую структуру панели, доступность и единое состояние. Атрибуция OpenStreetMap и условия исходного снимка находятся в `map-view/LICENSE.md`.
