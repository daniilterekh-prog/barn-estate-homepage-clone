# Проверка комплекта

[standalone.json](standalone.json) — отдельный HTTP-сервер, только файлы `site/`, все внешние сетевые ресурсы заблокированы. 37 записей и все фотографии доступны локально. Проверены пять направлений на 320/390/768/1440/1920px, текущие размеры фильтров, одна шапка, отсутствие переполнения, 6→12 карточек, поиск/пустая выдача/сброс, черновик/применение формы, URL, полный список карты, ограничения аренды, избранное после перезагрузки, контекст заявки, квиз, наведение и мобильное меню. Реальных отправок нет. Ошибок JavaScript/HTTP и обращений к внешним ресурсам нет.

- [Телефон 390px](catalog-390.png).
- [Десктоп 1440px](catalog-1440.png).
- [Проверка распакованного ZIP](archive-check.json).

`tools/verify_package.py` проверяет SHA-256 каждого файла сайта и отсутствие лишних/пропущенных файлов. Дополнительный браузерный тест `tools/check_standalone.cjs` использует существующий Playwright: `CATALOG_URL` задаёт URL, `PLAYWRIGHT_MODULE` — путь к модулю при необходимости, `CHROME_BIN` — установленный Chromium/Chrome, `PROOF_DIR` — папку результатов. Новых зависимостей для обычного запуска сайта нет.
