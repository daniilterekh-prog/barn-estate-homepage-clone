# Подключение страницы контактов

## Готовая страница

Точка входа — `html/index.html`. Перенеси рядом папки `css`, `js`, `assets`, `data` с сохранением относительных путей. CSS и JS уже подключены. Сборщика нет. Для просмотра нужен обычный HTTP-сервер.

`index.html` в корне пакета перенаправляет к полной странице. Рабочая версия находится в `html/index.html`.

## Фрагменты для шаблона сайта

1. `html/01-header.html` — skip link, хедер, мобильное меню и JSON девяти разделов навигации.
2. `html/02-contacts.html` — H1, переключатель и информация трёх офисов с картами и способами связи.
3. `html/03-footer.html` — футер.
4. `html/04-contact-dialog.html` — диалог связи.

Фрагменты извлечены из полной страницы, не загружаются через `fetch` и сами ничего не подключают. Их пути рассчитаны относительно `html/index.html`. При переносе в другой маршрут перебазируй пути к `css`, `js`, `assets`; используй подключения из `<head>` полной страницы в том же порядке. Не добавляй фрагменты второй раз поверх готовой страницы.

Сохрани `class="contacts-page"` у `body`. Страница использует `#main`, `.site-header`, `#site-mobile-menu`, `.office-tabs`, `.office-panel`, `footer`, `.contact-dialog` и JSON `#catalog-header-navigation`. Контроллер `contacts.js` ожидает эти части в DOM; для компонента Vue/React нужно включить все части страницы и запускать контроллеры после монтирования. Хедер/футер подключены собственными копиями, существующие общие файлы финальных узлов заменять не нужно.

## CSS

- `css/contacts.css` — шрифты, компоновка, офисы, кнопки, мобильные вкладки и диалог.
- `css/vendor/media-header.css` — хедер и его мобильная панель связи.
- `css/vendor/header-navigation.css` — выпадающие подменю по «Избранному».
- `css/vendor/page-breadcrumbs.css` — хлебные крошки.
- `css/vendor/footer.css` — футер.

Шрифты находятся в `assets/fonts`, SVG — в `assets/icons`, исходная лицензия Material Call — в `assets/licenses`.

## JavaScript

- `js/vendor/media-header.js` создаёт строку направлений и панель связи, поддерживает хедер и мобильное меню.
- `js/contacts.js` управляет вкладками офисов, мобильным меню и контактным `dialog`, предоставляет существующий контракт `window.__barnesOwnerForm.open` для хедера.
- `js/vendor/header-navigation.js` раскрывает девять подменю мышью, касанием и клавиатурой.
- `js/vendor/page-breadcrumbs.js` создаёт крошки и обновляет их при смене состояния хедера.

Все ссылки на телефон, почту, карты и мессенджеры обычные. Диалог содержит ссылки, формы заявки и отправки в CRM в этом пакете нет.

## Контент и карты

HTML статический. `data/content-sources.json` хранит данные и происхождение, но не загружается страницей как API. Изменение только JSON не меняет отображаемую страницу.

Для смены адреса обнови текст `address`, `aria-label` маршрута, `href` маршрута, `title` и `src`/`data-src` iframe, ссылку открытия карты и запись в JSON. Для скрытых офисов карта подключается при первом выборе вкладки. Поиск и маршрут используют адрес здания, номер помещения показывается в тексте.

Мессенджеры, единый телефон и почта взяты из согласованной страницы агентства. Личные контакты филиалов не добавлены. Петербургский адрес подтверждён пользователем: наб. реки Мойки, 59, БЦ «Сенатор», пом. 307.

Статическое превью сохраняет `noindex,nofollow`. При установке на основной сайт разработчик отдельно настраивает боевой URL, метаданные и индексацию. Внутренние ссылки хедера/футера ведут на существующий сайт; ссылки мессенджеров и карт внешние.

## Пересборка пакета

Из корня канонического репозитория: `python3 main-site/handoff/contacts/tools/build.py`. Скрипт читает runtime-файлы исходной страницы, перебазирует только пути, извлекает HTML-фрагменты и обновляет `SOURCE.json`. Не используй пакет как второй независимый источник для правок исходной страницы.

`tools/verify.cjs` проверяет самостоятельную загрузку, совпадение с исходником, адаптив и состояния через установленный Playwright. URL задаются `PACKAGE_URL` и `SOURCE_URL`, путь к библиотекам — `CTK_NODE_MODULES`. Проверочные инструменты не являются зависимостью страницы.
