# Цвета и состояния

| Роль | Значение |
| --- | --- |
| Основной текст | `#1e1e1e` |
| Вторичный текст | `#4f4d49` |
| Подписи метаданных | `#656462` |
| Фирменный бордовый | `#8b1d25` |
| Линии контента | `#d8d6d2` |
| Рамка кнопок связи | `#8b8986` |
| Белая поверхность | `#ffffff` |
| Фон карты до загрузки | `#f1f1f1` |

Активная вкладка: бордовый текст и нижняя линия2px. Неактивные — вторичный текст, прозрачное подчёркивание. Кнопка маршрута — бордовый фон и белый текст; hover — #70171e. Остальные кнопки связи прозрачные с рамкой; на устройствах с hover получают бордовый фон и белый текст. Цветные SVG мессенджеров сохранены.

Подменю — белая панель, рамка1px, радиус1px, тень0 8px 24px #00000014. Hover ссылки — #8b1d25 и вес400. Видимый фокус бордовый, обычно2px; на мобильных вкладках outline смещён внутрь области прокрутки. Проверочные снимки состояний хранятся в исходной странице; полный computed style покоя — в MEASUREMENTS.json.
