# Происхождение

Контент, фотографии, иконки и шрифты перенесены из утверждённых текущих страниц BARN Estate. Точные исходные URL и хэши — в SOURCE.json каждого раздела. Это передача текущего проекта, без смены прав на ассеты.

Splide — существующий компонент исходной главной; лицензия MIT сохранена в SPLIDE-LICENSE.txt. Copyright-заголовки исходных Vue/Nuxt-модулей сохранены в vendor JS. Новые сторонние зависимости в страницы не добавлены.
