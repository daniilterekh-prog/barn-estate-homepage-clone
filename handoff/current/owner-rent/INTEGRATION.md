# Собственникам — аренда — перенос по блокам

1. Открой html/ — точный эталон текущей страницы. В нём сохранён vendor runtime Nuxt/Vue, а исполняемый inline-JS и CSS вынесены в отдельные файлы. URL-адаптер handoff-bootstrap.js нужен только этому техническому эталону.
2. Для новой реализации используй ./html/page-shell.html и блоки из blocks/. Это независимый JS-адаптер без Nuxt и без подмены браузерных API. block.html не повторяет системную оболочку. Расставь фрагменты по комментариям BLOCK.
3. Подключи page.css один раз, CSS вставленных блоков и init-blocks.js. Сохрани атрибуты body, классы контекста, data-v-* и уникальность ID. Меню/модальные окна подключай один раз на страницу.
4. Общие изображения и шрифты — ../shared/assets/. Оригинальные URL и SHA — SOURCE.json. Пути относительные. Не меняй структуру распакованного комплекта до проверки.
5. Для форм внутри блоков API подключается через barn:submit / barn:subscribe / barn:search. Общие модальные формы находятся в shared/js/home-quiz.js и shared/js/expert-dialog.js: подключи отправку в их валидируемом обработчике submit. В текущем комплекте данные никуда не отправляются. Глобальные ссылки, каталог и якоря адаптируй к конечным маршрутам.
6. После переноса проверь 390/768/1440px, клавиатуру, фильтры, вкладки, слайдеры и формы.
