# Амбассадоры

[HTML](html/) · [CSS](css/) · [JavaScript](js/) · [Изображения и шрифты](assets/) · [Блоки](blocks/) · [Данные](data/)

Верхний уровень страницы сразу разделён по типам файлов. Файлы секций лежат прямо в html/, css/ и js/ с одинаковым номером и названием. В blocks/ — их превью и описание. [Инструкция](INTEGRATION.md).

Превью полной страницы — html/index.html. Запусти HTTP-сервер из общего корня handoff/current; file:// не подходит для JS-модулей. Общие формы подключаются из ../shared/js/. Отправка заявок в превью отключена.
