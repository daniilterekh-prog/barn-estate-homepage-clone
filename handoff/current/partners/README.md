# Амбассадоры — текущая передача

[Полная страница](code/html/) · [Все блоки](blocks/) · [Оболочка для сборки](code/html/page-shell.html) · [Интеграция](INTEGRATION.md)

- code/html/index.html — полная вёрстка.
- code/css — текущие CSS и вынесенные inline-стили.
- code/js — JS, исходный vendor runtime и переносимый адаптер блоков.
- code/data — сохранённые данные.
- ../shared/assets — общие изображения, шрифты и иконки, без повторных копий.
- blocks/NN-name — отдельные block.html, block.css, block.js и превью.

Для просмотра запусти HTTP-сервер из корня общего пакета: python3 -m http.server 8080. Открой /partners/code/html/ или /partners/blocks/. Файл через file:// не поддерживает JS-модули и fetch.

Полная страница сохраняет исходную клиентскую логику; блоки используют независимый адаптер и общие CSS-зависимости. Для продуктового проекта замени snapshot GET/preview-обработчики на реальные API. Отправка заявок в пакете отключена.
