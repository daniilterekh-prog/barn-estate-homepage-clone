# Главная СПб — готовый пакет разработчику

**Полная страница:** [html/index.html](html/index.html). **Скачать комплект:** [home-spb-developer.zip](home-spb-developer.zip).

Постоянная папка главной BARN Estate Санкт-Петербург. Снимок текущей согласованной страницы от 10.11.2026: херо ZEN, шесть направлений, 13 объектов СПб и 8 курортных/зарубежных карточек, ЛДМ и новые иллюстрации направлений, Людмила Белоусова первой в команде и в виджете, Schema.org и исправленный мобильный заголовок «Коллекционера». Используется изолированный UI-кит главной СПб v1.0.3; новые изменения московского мастера автоматически не переносились.

## Состав

| Папка / файл | Назначение |

Отдельные HTML-фрагменты не заявлены автономными блоками: страница использует сохранённый Vue/Nuxt runtime. Не удаляйте его и атрибуты `data-v-*` из HTML. Для переноса в CMS используйте данные и структуру как источник, сохраняя согласованный внешний вид.

## Самостоятельный запуск

Распакуйте ZIP и сохраните структуру папки `home-spb/`. Из неё:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080/html/`. Корневой `index.html` — только переход на полный документ. `file://` не подходит для модулей JavaScript. npm и доступ к исходному репозиторию для просмотра не нужны.

Локальные ресурсы страницы собраны внутри пакета. Внешними остаются пользовательские переходы на сайты объектов, соцсети, email, телефон и карту. В `js/handoff-bootstrap.js` находится адаптер путей сохранённой Nuxt-сборки: исторические технические URL перенаправляются на локальные файлы. Пока используется эта сборка, адаптер должен загружаться первым; исходные пути `/main-site/pages/home-spb/` на вашем сервере создавать не нужно.

## Редактирование и подключение

- `css/home-*.css`, `css/media-header.css` — оформление; `js/home-content.js` — региональные тексты и виджет; `js/home-recommendations.js` — карточки; `js/home-owner-form.js` — квиз.
- Данные каталога также встроены в HTML/Nuxt payload. `data/*.json` оставлены для интеграции и сверки; простая правка отдельного JSON сама по себе не меняет встроенный снимок. Канонические изменения делаются в `barnes-sites/main-site/pages/home-spb/`, затем материализуются штатными инструментами страницы и повторно экспортируются.
- `data/spb-schema.json` — готовый JSON-LD, уже установленный в head. Не вставлять его повторно. Должность Людмилы: **руководитель филиала BARN Estate в Санкт-Петербурге**.
- Четыре направления ведут на barnestate-spb.ru. «Курортная» и «Зарубежная» по решению пользователя ведут на barn-estate.ru. Ссылки и телефоны не следует менять механической заменой домена.
- Полная страница рассчитана на HTTP-размещение вместе с соседними папками. При изменении структуры файлов обновить ресурсную карту/адаптер или заменить сохранённый runtime собственными компонентами. Подключение к действующей CMS и публикация на боевом домене не выполнялись.

## Что подключить перед боевым запуском

Формы, подписка и серверная выдача не подключены к CRM/API. Превью не отправляет заявки; транспортные ограничения находятся в адаптере и сохранённом GET-адаптере `js/inline-*.js`. Разработчик должен подключить реальные обработчики, согласие, валидацию и подтверждение успешной отправки, после чего проверить весь путь заявки. Общий поиск и поиск известных ID перенаправляют на региональный каталог; полноценные серверные фильтры требуют интеграции.

В пакете сохранены согласованные общие контакты: +7 (499) 272-48-72, moscow@barn-estate.com; офис — наб. реки Мойки, д. 59, БЦ «Сенатор», пом. 307. Остальные сотрудники, отзывы, новости и офисная иллюстрация требуют редакционной сверки перед боевым запуском. Это не новая полная локализация контента.

`noindex,nofollow` сохранён для превью. Schema.org подготовлена для barnestate-spb.ru. При реальном запуске согласовать актуальные данные, установить canonical/robots/sitemap и разрешить индексацию. Удалённые/скрытые исходной страницей видеоресурсы не включены: текущий херо использует изображение ZEN, отдельного видеоблока нет. Неиспользуемый браузерный ключ API карт заменён явным не секретным значением HANDOFF_MAP_KEY_NOT_CONFIGURED, чтобы сохранённый plugin проходил инициализацию; для интерактивной API-карты разработчику нужен собственный ключ. Обычная ссылка на карту работает.

Две иллюстрации направлений созданы image_gen, ЛДМ — официальный рендер застройщика; происхождение находится в data/direction-image-sources.json. Фотографии конкретных объектов не подменены генерациями. Исходные уведомления об авторских правах и лицензия Material Icons сохранены.

## Обновление комплекта

Одна постоянная папка и один актуальный ZIP. История — в Git. Сборщик `tools/build.cjs` использует каноническую страницу и установленный JSDOM (можно задать `JSDOM_MODULE`); не предназначен для пересборки защищённых московских узлов. После обновления выполнить проверки и `tools/archive.py`.
