# Проверки готового пакета

- `report.json`: Chromium, 320/390/1440px; внешний сетевой доступ заблокирован. Гидратация, Schema.org, отсутствие переполнения, 6 направлений (4/3/3/3/3/5 карточек), 21 изображение рекомендаций, 25 портретов, избранное, 2 избранных проекта, квиз Людмилы, Escape/возврат фокуса, меню, региональный поиск. Переход поиска перехвачен тестом без обращения к сайту назначения.
- `parity/report.json`: попиксельная сверка херо, направлений и избранного проекта с канонической исходной страницей на 390/1440px. Внешний вид и геометрия сохранены.
- `extracted/report.json`: повторная проверка распакованного ZIP на отдельном HTTP-сервере, не имеющем доступа к исходной папке.
- `files.json`: 187 прямых ссылок HTML/CSS, 220 контрольных сумм runtime; отсутствующих файлов и внешних зависимостей ресурсов нет.
- `../ARCHIVE.json`: SHA-256 ZIP и всех упакованных файлов; проверка целостности ZIP. Сам файл находится рядом с ZIP, чтобы не создавать циклическую контрольную сумму.

Снимки экранов сохранены здесь в GitHub, в ZIP не включены. Файлы `tools/check.cjs`, `tools/parity.cjs` — воспроизводимые проверки; пути установленного Playwright/Sharp можно задать переменными PLAYWRIGHT_MODULE/SHARP_MODULE. Пример: `CHECK_URL=http://localhost:8080/html/ node tools/check.cjs`.

Рабочая версия: 10.11.2026. Это проверка экспортированной копии, не подтверждение подключения к CRM или публикации на боевом домене.
