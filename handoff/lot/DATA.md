# Данные и Intrum

Формат реальной выгрузки пока не выбран. API не подключён, ID полей неизвестны. Передаётся логика и готовая публичная модель рендерера, а не коннектор Intrum.

- `data/lot-601669.json` — публичное наполнение, с которым проверен пакет.
- `data/intrum-field-map.csv` — 73 строки сопоставления: группа/название → блок/правило; API ID пока пустые. Внутренние примеры значений удалены.
- `data/intrum-export-rules.md` — схема отбора и показа без рабочих контактов/CRM-скринов.
- `data/description.txt` — полный текст демонстрационного описания.
- `data/ui-kit.json`, `data/lucide-source.json` — кит и происхождение SVG; лицензии в assets/licenses/.

| Поле публичной модели | Назначение |
|---|---|
| id/title/cover.src | Обязательны рендереру; ID — контекст действий |
| priceRub/displayPrice/locationLabel | Херо; цена один раз: на desktop над стрелками, на телефоне над характеристиками; география над заголовком |

| floorPlan{src,alt,title?,rooms?} | Собственный план; rooms необязателен. В демо площади комнат введены по листу вручную — на карточке CRM таких полей нет |

## Автоматическая публикация

Только явное **«Выгрузка на сайт:Да»** + допустимый статус + корректные обязательные данные. `Нет`/пусто — запрет; для ранее опубликованного объекта снять с витрины/похожих. Статус «Свободная» не заменяет флаг выгрузки. Демонстрационное превью сделано вручную по поручению пользователя.

Не передавать целую CRM-карточку в браузер. Комиссия компании, кадастровый номер, собственник/события/комментарии, оценки ликвидности, рабочие контакты, источник и рекламные настройки исключаются серверным allowlist. Поля для Домклика/Циан не заменяют сайт. Сортировочное название ЖК не доказывает связь с публичной страницей проекта.

«О квартире» получает одно полное поле. Не сочинять резюме/преимущества и не разбирать его по дому/расположению. Raw HTML должен быть очищен сервером с сохранением абзацев/списков; frontend вставляет текст через textContent.

Перед настоящей выгрузкой исправить расхождения в CRM: кухня11 против10,66 м² в тексте/плане, потолки2,7 против2,65; проверить комнаты/спальни. В демо точные значения кухни/потолков взяты с предоставленного плана, спальни скрыты. Это ручные настройки демонстрации, не автоматический парсинг описания.

Медиа и условия в примере не подтверждают текущее наличие/цену. Автоматическое ранжирование, точное совпадение бюджета и назначение брокера не реализованы. Если собственного плана нет, работает запрос материала; если описание пустое, блок не выводится. Удалённый блок стоимости/условий не восстанавливать из полей сделки.
