# UI-кит и состав

Основа — действующий BARN Estate v1.0.6 и локальные компоненты согласованной страницы ЖК. Tilda Sans (локальные WOFF2), белые контентные поверхности, бордовый #8b1d25, исходные контейнеры/отступы/стрелки. Круглые стрелки48/56/68 px с глифом11×22; исходный режим хедера/компактной навигации сохранён. Lucide — локальная лицензированная копия, stroke1.5, цвет #656462,24/22px; декоративные SVG скрыты от скринридера.

Херо№3: фото на всю ширину; география над заголовком; крупная цена над стрелками справа; без видимого счётчика между стрелками. Заголовок возвращён ниже: цена над стрелками не создаёт верхний отступ строки CTA на desktop. Цена22/30/36/42px по ширине; CTA и центры стрелок на одной линии. Высота повторяет существующую главную, без изменения размеров херо. Нижняя строка характеристик/линия и плотные отступы сохранены.

Порядок: херо → характеристики → планировка → о квартире → о доме → расположение → консультация → похожие → рассылка → футер. Блока «Стоимость и условия покупки» и промежуточного закреплённого оглавления нет. После херо появляется компактный хедер. Плавающий элемент — эксперт, не цена.

Описание: текст и фото в двух колонках от768px, на телефоне текст затем фото. Поле целиком; визуальное сворачивание с «Читать далее»/«Свернуть». План: большой исходный лист слева, сведения справа; до1024px лист первым. Подземный паркинг — в характеристиках дома. Похожие карточки — CSS страницы ЖК, сетка3/2/1.

Все величины оставлены в отдельных CSS-файлах, порядок подключений сохранён. Не переносить общие стили защищённых узлов и не заменять локальный кит чужим фреймворком. Предусмотренные роли/контейнеры/кнопки не нужно стилизовать заново.
