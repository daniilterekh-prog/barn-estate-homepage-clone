# Страница лота BARN Estate — пакет разработчику

Актуальная постоянная папка `handoff/lot/`. Пример — квартира601669 у Лахтинского разлива, выбранный херо№3. Открывается сразу без query-параметров. История — в Git; при правках обновляются эта папка и один ZIP.

Запуск **из корня этой папки**:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8080/html/index.html`. npm/сборщик не нужны. Сохранять взаимное расположение папок. Открытие через HTTP предпочтительно `file://`.

**Полная страница и HTML-фрагменты — альтернативы.** В полной странице блоки уже собраны; повторно вставлять фрагменты не нужно. По умолчанию JS строит содержимое `#main` из `window.BARNES_LOT_DATA`. Фрагменты служат для переноса разметки в собственный шаблон, см. INTEGRATION.md.

Включены последние изменения: крупная цена над стрелками на desktop и над характеристиками на телефоне, без видимых цифр между ними; цена за м² справа от окон; полный текст с «Читать далее»; крупная планировка; подземный паркинг в доме; карточки похожих как в ЖК; блок стоимости/условий удалён. Есть готовые хедер, футер, плавающий эксперт и рассылка.

Пакет передаёт визуальный шаблон. Intrum API/реальные ID полей, отправка заявок, сервис рассылки и автоматический подбор похожих **не подключены**. Формы готовят письмо, пользователь отправляет его сам. Данные/экспликация/похожие — демонстрационные; источник и ограничения описаны в DATA.md. Карта и внешние ссылки требуют сети; визуальные ресурсы локальные.
