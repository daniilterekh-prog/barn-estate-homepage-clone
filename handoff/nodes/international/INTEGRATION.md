# Подключение · Зарубежная недвижимость

1. html/index.html — точная полная страница с действующими контроллерами. Запусти HTTP-сервер из корня handoff/nodes; file:// не поддерживается. js/handoff-bootstrap.js нужен только для просмотра сохранённого runtime по другим путям.
2. html/NN-name.html, css/NN-name.css, js/NN-name.js — соответствующие файлы одного блока. blocks/NN-name/ содержит превью и block.json с зависимостями. Подключи css/page.css один раз: это контекст UI-кита, шрифтов и адаптивной сетки. Классы и data-v-* сохраняй.
3. Автономный blocks-runtime.js поддерживает слайдеры, FAQ, способы связи, согласие, ссылки подборок, меню, разворот текста и обращения к эксперту. Квиз подключён из сохранённого node-expert-dialog.js; вопросы и фото своего департамента.
4. Каталог, полный фильтр и карта связаны предметным состоянием. Их оригинальные контроллеры находятся в js/ и перечислены в data/runtime.json. Для переноса интерактивного каталога используй их вместе с HTML полной страницы: отдельные превью карты/фильтров показывают состояние интерфейса, но не подменяют интеграцию с данными.
5. Отправка заявок остаётся демонстрационной. Для новой интеграции подпишись на barn:request/barn:submit/barn:subscribe и подключи свой backend; не показывай подтверждение отправки без ответа сервера. Навигационные URL ведут в существующие страницы BARN Estate.
6. Ассеты страницы — assets/, общие данные и происхождение — SOURCE.json. Полные URL и SHA сохранены. Сервис Яндекс Карт требует сети; его SDK не архивируется. Ссылка на картинку в GitHub не означает передачу прав.
7. Проверяй минимум320/390/768/1440px, клавиатуру, хедер после скролла, два ряда пилюль, пустую выдачу, сброс и мобильный портрет по пояс.

## Переносимый квиз

Для отдельных блоков подключи `<script src="js/expert-quiz.js"></script>` один раз и задай body `data-node-filter-direction="international"` вместе с общим CSS-контекстом. Пути к фото уже направлены в assets/. В превью отдельных блоков отсутствует handoff-bootstrap.js: браузерные API не подменяются. Полная html/index.html сохраняет технический relocation-bootstrap для точного runtime. Портативный квиз отправляет отменяемые события barn:request и barn:submit, detail.values содержит ответы/контакт. Сетевых запросов на отправку нет; обработчик интеграции должен явно подключить backend.
