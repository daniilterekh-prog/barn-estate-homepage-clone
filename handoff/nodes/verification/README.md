# Проверки пакета

static.json проверяет пути, синтаксис и SHA; browser-pages.json и browser-blocks.json — браузерные проверки. scan-unresolved.json содержит кандидаты из строк JS, которых нет в этом направлении: общий квиз содержит профили всех пяти департаментов, а строковые пути могут считаться относительно документа или JS. Это журнал сканирования, не список обязательных запросов браузера; реальные сломанные изображения проверяются отдельно. Яндекс Карты остаются внешним сервисом.
