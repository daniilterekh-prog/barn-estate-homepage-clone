# План и решения сборки

1. Закрепить текущий source commit и публичный origin/master. Канонический путь остаётся main-site/pages/собственники загород; экспорт — отдельный main-site/handoff/sobstvenniki-zagorod.
2. Перенести граф HTML/CSS/JS/изображений/шрифтов в html/css/js/assets, сохраняя исходный порядок и структуру DOM. Изменять только ресурсные пути и выносить inline CSS/JS. Полная страница и фрагменты подписаны.
3. Сохранить данные, происхождение, инструкцию интеграции. Не подключать отправку форм и не менять исходную страницу.
4. Проверить локальные ссылки и хеши, запуск без внешних ресурсов, мобильный вид, меню, формы, диалог и совпадение с исходником на телефоне/компьютере.
5. Создать один ZIP с контрольными суммами, проверить распаковку и сценарии из ZIP, затем commit/push исходного и публичного пакета с обновлением каталогов.

Наследованный неактивный CSS ссылается на 709121d4e9a3cf06.webp: файл перенесён из сохранённого публичного city/assets с тем же именем-хешем. Защищённый узел используется только для чтения. Публикация работает через отдельный Git index и не затрагивает рабочие файлы других задач.
