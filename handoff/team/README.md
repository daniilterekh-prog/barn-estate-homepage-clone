Локальный запуск из этой папки:

```sh
python3 -m http.server 8080
```

Открыть `http://localhost:8080/html/index.html`. npm, сборщик и серверная часть не нужны. Для переноса сохраняй структуру папок пакета; картинки и шрифты уже локальные. CSS/JS исполняются в том же порядке, что на рабочей странице. Изменены только пути ресурсов и переходов на соседние страницы; функции и оформление сохранены.

Проверены16ширин320–3840px, все9подменю, поиск и фильтры, мобильные контакты/меню, форма и режим без JS. Снимки исходника и экспорта совпали с допуском1/255 на канал менее чем у0,1%каналов на390/1440/1920px. В ходе проверки пакет не запрашивал внешние ассеты. Ссылки на другие разделы ведут на опубликованный сайт; для просмотра этой страницы они не нужны.

Форма сохранена как на главной: в превью отправка заявок не подключена. После корректного заполнения выводится «В превью отправка заявок не подключена. Данные не отправлены.». Подключение CRM — отдельная задача интеграции.

Канонические исходники — [barnes-sites/main-site/pages/team](https://github.com/daniilterekh-prog/barnes-sites/tree/main/main-site/pages/team). Эта папка — отдельная передача разработчику, а не второй источник для редактирования страницы. Пять утверждённых узлов и их общие файлы не менялись.
