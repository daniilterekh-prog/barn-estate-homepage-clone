# Цвета, рамки и состояния

Значения перенесены из текущего кита страницы и её компонентов. Нейтральные цвета рамок/плейсхолдеров и полупрозрачные разделители сохранены по готовым компонентам; секции каталога и CTA белые.

| Роль | Значение |
| --- | --- |
| Основной текст | `#1e1e1e` |
| Акцент и активный фильтр | `#8b1d25` |
| Hover основной кнопки | `#74171e` |
| Поверхности страницы, поиска, меню | `#fff` |
| Рамка поиска в покое, как в узлах | `#8b8986` |
| Плейсхолдер/лупа поиска, крошки | `#656462` |
| Разделитель хедера «Избранного» | `rgba(30,30,30,.14)` |
| Рамка подменю | `#e4e4e4` |
| Тень подменю | `0 8px 24px #00000014` |
| Рамки направлений/разделитель CTA | `rgba(139,29,37,.3)` |
| Имя на карточке | `#fff` |
| Должность на карточке | `rgba(255,255,255,.9)` |

Поиск в покое не имеет красной рамки. При фокусе рамка становится бордовой, как у поиска каталога узлов; дополнительного красного outline вокруг поля нет. У остальных клавиатурных контролов сохраняется видимый focus-visible.

Активный фильтр:бордовый фон/рамка, белый текст. Hover фильтра:бордовая рамка/текст. В раскрытом хедере название активного раздела и hover ссылки — бордовые. Прямоугольные элементы имеют радиус1px; исходные круглые иконки связи сохранены.

Нижний градиент карточки: `linear-gradient(0deg,rgba(0,0,0,.9),rgba(0,0,0,.55) 45%,transparent)`. Монохромные фотографии команды сохранены; ретушь и новые подложки не добавлялись. Цвета/фон самой формы скопированы с главной без изменений.
