# Вакансии BARN Estate — передача разработчику

Одна актуальная версия. [ZIP](vacancies-developer.zip) · [Полная страница](html/index.html) · [Текущее публичное превью](https://daniilterekh-prog.github.io/barn-estate-homepage-clone/vacancies/).

Передавай папку целиком или один ZIP. После распаковки из папки `vacancies` запусти `python3 -m http.server 8000` и открой `http://localhost:8000/html/`. npm, сборка и внешние библиотеки не нужны. Все изображения и шрифты локальные.

| Путь | Назначение |
| --- | --- |
| `html/index.html` | Полная самостоятельная страница с head/body и подключениями |
| `html/01-header.html` | HTML-фрагмент: skip-link, хедер, крошки и панель контактов |
| `html/02-main.html` | HTML-фрагмент: main, hero, преимущества, вакансии и CTA |
| `html/03-footer.html` | HTML-фрагмент: футер |
| `html/04-dialogs.html` | HTML-фрагмент: мобильное меню |
| `css/` | Стили в порядке, указанном в полной странице |
| `js/` | Хедер/меню/контакты, подменю направлений и фон CTA |
| `assets/` | Только12 текущих изображений, SVG и шрифтов |
| `data/` | Редакционные данные и происхождение текущих ассетов |
| `DESIGN.md` | Оформление, размеры и адаптив |
| `SOURCE.json` | Исходный commit, преобразования путей и SHA-256 runtime |
| `VERIFICATION.json`, `CHECKSUMS.sha256` | Проверки и целостность комплекта |

Фрагменты не открываются отдельно. Собирай их внутри body с классами `barnes-home-typography barnes-media-header career-page` в порядке01→02→03→04. Не вставляй одновременно полную страницу и фрагменты. Пути `../css/`, `../js/`, `../assets/` рассчитаны на папку html; при интеграции сохраняй структуру или корректируй ссылки. Сохраняй data-атрибуты, id и классы: они связывают CSS и меню. Корневой index.html — только переход на полную страницу.

Кнопки отклика открывают исходную страницу работодателя hh.ru в новой вкладке; «Смотреть вакансии» — якорь. «Написать нам» открывает почтовый клиент через mailto:moscow@barn-estate.com. Формы, серверной отправки, CRM и аналитики в комплекте нет. Тесты сообщения/резюме не отправляют. Навигация ведёт на barn-estate.ru и согласованные страницы превью; для боевого сайта проверь соответствие маршрутов. Перед боевой установкой проверь актуальность вакансий у HR, robots/canonical/OG; в превью оставлен noindex,nofollow и canonical https://barn-estate.ru/vacancies/.

Источники — действующий BARN Estate UI-kit1.0.3, Tilda Sans300/400/500, изолированные копии хедера/футера и CTA финального городского узла. Новые библиотеки, API и платные компоненты не добавлены. Hero2304×1536 — утверждённый владельцем расширенный кадр: исходная группа сохранена1:1 после общей тёплой цветокоррекции, image_gen использован для интерьера. WebP без потерь совпадает с PNG; оригиналы остаются в приватных исходниках. Происхождение — data/sources.json.

Канонические исходники: barnes-sites/main-site/pages/vacancies, ветка codex/vacancies-20261109. Готовая передача: barnes-sites/main-site/handoff/vacancies. Публичный экспорт: barn-estate-homepage-clone/handoff/vacancies. Обновляй эту же папку и vacancies-developer.zip. Предыдущие варианты — в Git. Сборщик: tools/build-handoff.py в канонической папке страницы; --package-only пересобирает ZIP после записи результатов проверки. Проверка файлов: `python3 tools/verify-files.py --archive vacancies-developer.zip`. Дополнительная браузерная проверка tools/verify-release.cjs использует Playwright только у разработчика (не зависимость сайта); BASE_URL указывает полный адрес html/index.html, REPORT_DIR — отдельную папку отчётов. Пять защищённых узлов и общие файлы не менялись. Боевой домен этим пакетом не обновлён.
