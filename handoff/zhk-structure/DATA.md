# Данные Intrum и правила вывода

Пакет содержит текущий статический визуальный шаблон. Фактические ID полей API и связь ЖК с лотами не подтверждены; интеграция должна сопоставить их по устойчивым ID на сервере. Названия ниже — контракт назначения, а не готовый API-запрос. Никакие внутренние контакты сотрудников и CRM-доступы не включены.

## Обязательная логика

Публиковать только разрешённые к выгрузке записи с валидным публичным названием. Нет значения — нет элемента; нет содержимого раздела — нет раздела и его якоря. Не писать тексты для каждого ЖК вручную и не достраивать характеристики из косвенных данных. Не выдавать общее число квартир за текущее наличие.

| Элемент | Источник | Правило |
| --- | --- | --- |
| H1, хлебные крошки, контекст CTA | Название жилого комплекса | Единое проверенное публичное имя |
| Hero-изображение и галерея | Фото | Только допустимые изображения; без подписи «визуализация» и видимого счётчика |
| Адрес/локация | Район города, улица, дом, метро | Использовать реально заполненные значения, не придумывать расстояния |
| Площадь под H1 | Площадь от / Площадь до | Только валидные границы; не подставлять отсутствующий конец диапазона |
| Цена под H1 | Подтверждённые опубликованные лоты | Цена по запросу, если цены нет; не использовать 0 как цену |
| Локация в сетке | Район города | Показать заполненную характеристику |
| Класс | Тип комплекса | Показать заполненное значение |
| Застройщик | Застройщик | Единое имя для сетки и FAQ |
| Всего квартир | Квартир в комплексе | Общее число, не «доступно квартир» |
| Год сдачи | Дата сдачи год | Необязательная ячейка; 0/пусто скрыть, `2 030` → `2030`; прошлый год не означает «сдан» |
| Отделка | Отделка | Необязательная ячейка; «Без отделки» — заполненное значение |
| Высота потолков | Высота потолков | Необязательная ячейка; положительное число или явный диапазон, 0/пусто скрыть |
| Описание проекта | Общее описание | Текст и одно фото; длинный текст раскрывается кнопкой |
| Инфраструктура комплекса | Инфраструктура, для презентации | Обычный текст; после двух непустых абзацев — «Читать далее», без фото |
| Расположение | Расположение, для презентации; карта | Текст и Яндекс Карта по валидной точке; две внешние кнопки не нужны |
| Квартиры и планировки | Отдельные опубликованные квартиры | Нужна проверенная связь с ЖК и реальные планы; текущие три формата — примеры |
| Условия покупки | Подтверждённые актуальные условия | Не выдумывать ипотечные ставки и акции; пример визуального блока не доказывает наличие условий |
| Застройщик/документы | Проверенное имя и публичные URL/файлы | Не выводить неподтверждённые историю, логотипы и скачивания |
| Похожие проекты | Выборка других разрешённых ЖК | Исключить текущий ID и дубли; текущие три карточки — статические примеры |
| Новости и эксперт | Общий контент BARN Estate | Не отдельные тексты для каждого ЖК |

## Ячейки дополнительных характеристик

`#project-optional-facts` — общий `<dl>` с четырьмя основными ячейками. Скрипт читает JSON из `#project-optional-data` и добавляет только заполненные поля, помеченные `data-optional-fact`. Повторный `render` заменяет лишь эти дополнительные узлы и сохраняет основные. Последняя нечётная ячейка занимает всю строку.

```js
const root = document.querySelector('#project-optional-facts');
window.BarnProjectCharacteristics.render(root, {
  handover_year: 2030,
  finishing: 'Без отделки',
  ceiling_height: '3,2–4 м'
});
```

Это пример вызова с уже проверенными публичными значениями. В реальном шаблоне четыре основные ячейки тоже формируются из заполненных данных на сервере; этот контроллер не получает и не редактирует их. Для серверного JSON безопасно экранировать `<` и закрывающие script-последовательности; текстовые значения выводить с HTML-экранированием.

Текущие `handover_year: 0` и `finishing: null` не показываются. Высота `3,15–7,4 м` сверена с официальной страницей проекта 25.11.2026; это не новая выгрузка CRM. `data/optional-preview.json` повторяет встроенный пример. Подробные правила нормализации — в `data/optional-characteristics-source.json`.

## FAQ и тексты

Шесть общих вопросов из `data/faq-template.json`, переменные `project_name` и `developer_name`. При пустом застройщике его вопрос скрывается, вопрос об отделке получает нейтральную версию: пять вопросов. Не склонять автоматически и не дублировать «ЖК» перед уже полным названием. Подстановки должны быть экранированы. В текущем HTML пример уже собран; JSON сам по себе не подменяет текст страницы.

Общие пары бровей/H2 находятся в `data/section-labels.json`; у H2 нет дополнительных описаний справа. Текст Intrum следует очищать от небезопасного HTML и приводить к непустым `<p>`. Для описания без фото убрать изображение и добавить `project-description--text-only`; контроллер применит текстовый предпросмотр. Без JavaScript весь текст описания/инфраструктуры остаётся доступным.

JSON с суффиксом `source` сохраняют происхождение и историю решения; встречающиеся в них пути `preview/...` относятся к каноническим исходникам. При интеграции путь к соответствующему runtime-файлу берётся из этого пакета. Эти JSON не являются автоматически загружаемым фидом. Не использовать первоначальное исследование как доказательство всегда заполненных полей.

## Планировки: обновлённая композиция

Слева — комнатность, стоимость, площадь и действие; справа — фото с общим текстом и открытием сохранённого плана. Вкладки комнатности убраны. Источник/условия: `data/floorplans-source.json`. Площадь примера не подписывается «от»: это не доказанный минимум свободного предложения. Нет цены — «По запросу», нет подтверждённого количества — нет числа вариантов. В боевом адаптере группировать реальные опубликованные лоты по комнатности, считать актуальные минимумы и количество; при наличии результатов действие ведёт в отфильтрованный каталог. 4+ и строку цены за м² выводить только из данных. Комнатность и число спален — разные поля.

## Ипотечный расчёт Calcus

В этом пакете Calcus считает по введённым пользователем данным. Цена/ставка пустые до ввода; 30% взноса и20лет — изменяемые общие исходные параметры. Связь с лотом/Intrum, банковские программы и автоподгрузка ставок не подключены. Внешний результат предварительный. Видимую ссылку поставщика сохранять; подробности в `data/mortgage-source.json`.
