# Сохраняемый UI-кит

Точная текущая композиция страницы, без нового дизайна. Общий референс — UI-кит главной BARN Estate v1.0.6 и локальные согласованные исключения страницы ЖК.

| Роль | Значение |
| --- | --- |
| Шрифт | Локальный Tilda Sans; 300 для заголовков/основного текста, 400 для действий/подписей |
| Основной акцент | Бордовый `#8b1d25`, белые контентные поверхности |
| Прямоугольные кнопки | Радиус 1 px, высота 70 px, на телефоне 58 px |
| Текст основных кнопок | 17 px до 1440, 19 px выше, 18 px на телефоне |
| H2 | 22 px до 540, 38 px до 1440, 44 px выше |
| Подписи в характеристиках/документах | 18 px / 400 / 1.4; до 767 — 16 px |
| Максимальная ширина контента | 1920 px с центрированием и адаптивными полями |
| Мобильные поля | 22 px до 540; точные компенсации scrollbar сохраняет `layout-gutters.css` |
| Секции | Мобильные 48 px сверху/снизу, десктопные `clamp(72px,6vw,100px)` |

H1 hero намеренно больше базового H2: Tilda Sans 300, на телефоне 38–48 px, далее до 88 px. В hero слева адрес, название, цена и площадь без карточек; справа две кнопки. До767px остаётся только «Консультация эксперта», выровненная с H1 по левому краю. Нижней фиксированной панели действий нет. Hero повторяет размеры главной по соответствующим брейкпоинтам; точные правила распределены между `hero.css` и `hero-laptop.css`.

Паспорт — фотография и общая сетка с основными и 0–3 дополнительными ячейками. Сетка адаптируется без пустых рамок. Значения наследуют 27 px на десктопе и 20 px на телефоне; подписи увеличены отдельно.

Галерея: два кадра на десктопе, один до 767 px, SVG-стрелки/свайп/увеличение. Видимых номеров и технических подписей нет. FAQ — две колонки с тонкими линиями и SVG-плюсом, одна до 540 px. Новости — формат главной. Похожие проекты — карточки городского узла продажи.

Финальный CTA использует общий портрет Руслана и тёмный фон; на экранах шире 1920 px фото ограничено центральной рамкой. Это утверждённое исключение к белым контентным поверхностям. Полный футер и плавающий эксперт повторяют текущую главную; чужие страницы и защищённые узлы не менялись.

CSS оставлен отдельными локальными слоями в исходном порядке, без объединения и повторной оптимизации. Контрольный документ кита: https://github.com/daniilterekh-prog/barnes-sites/blob/main/main-site/pages/residential-complex/structure/UI-KIT-LOCK.md.

Планировки обновлены по референсу: четыре согласованные колонки строк слева, фотография с затемнённой нижней частью справа. На планшете действие строки переносится ниже, на телефоне весь блок становится вертикальным. Фото и левый контент имеют одинаковую высоту на десктопе; кнопка подборки остаётся основным CTA.

Условия покупки и документы до767px — независимые карусели по одной карточке, SVG-стрелки/свайп, без автопрокрутки. От768px — прежняя сетка. Локальные слои `mobile-cards.css`/`mobile-cards.js` используют уже включённый Splide4.1.4/MIT ([документация](https://splidejs.com/guides/options/)).

Порядок27.11.2026: блок `#expert` («Консультация эксперта») расположен сразу после документов, перед `#faq`. В конце страницы повторного CTA нет. Номера HTML-фрагментов соответствуют текущему порядку секций.
