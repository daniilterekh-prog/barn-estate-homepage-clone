## UI: канонические компоненты

Источник — [barnes-assets / UI-kit](https://github.com/daniilterekh-prog/barnes-assets/blob/main/ui-kit/README.md), версия `4aa6ef04fe6b61105589b331a94fa003ea1b1487`. Точные пути и SHA-256 всех перенесённых файлов: [ui-source.json](ui-source.json).

- Header: `blocks/nodes/first-degree/header/fragment.html`, общий OwnerHeader без строки направлений. Сохранены SVG, логотип, каналы связи, mobile grid и размеры. Для внутренней страницы оболочка расположена в потоке и использует тёмный логотип на белом фоне.
- Footer: `blocks/nodes/first-degree/footer/fragment.html` + `owner-footer.css`. Полный тёмный футер с девятью группами навигации, контактами, соцсетями, юридической ссылкой и обратной связью. Цвет `#262626`, сетка и адаптив из источника.
- ListingLot и ListingProject: `blocks/nodes/first-degree/card-lot/fragment.html` и `card-project/fragment.html`. Сохранены структура, `data-v-*`, SVG-сердце, адрес над названием, характеристики, ID лота рядом с ценой, две компактные кнопки. Для старых объектов меняются только данные.
- Сортировка: исходный `quick-filter-dropdowns/quick-filters.js` и CSS; скрытый native select служит адаптером состояния. Страница предоставляет требуемый `BarnesFilters` только для сортировки. Сохранены клавиатурное управление, Escape, возврат фокуса и бордовые состояния.
- В `ui/` CSS и dropdown перенесены без изменений; хэши проверяются тестом. Изображения и шрифты скопированы только по используемым ссылкам. Новые зависимости, сторонние наборы иконок или шрифты не добавлены. `favorites.css` содержит только композицию страницы и состояния избранного.

Контракты: [FirstDegreeNode](https://github.com/daniilterekh-prog/barnes-assets/blob/main/ui-kit/first-degree.md), [ListingCard](https://github.com/daniilterekh-prog/barnes-assets/blob/main/ui-kit/components/listing-card.md), [CardActionCompact](https://github.com/daniilterekh-prog/barnes-assets/blob/main/ui-kit/components/card-action-compact.md), [OwnerHeader](https://github.com/daniilterekh-prog/barnes-assets/blob/main/ui-kit/components/owner-header.md).

## Поведение

- Общий ключ публичного каталога `barnes-catalog-favorites` хранит только массив ID. Старые числовые ID сохранены, ID ЖК поддерживаются отдельно. `BarnesFavorites.getIds()/add(id)/remove(id)` — адаптер для подключения карточек других страниц.
- Кнопки каталога из сохранённого снимка подключены к той же подборке. Переключатели «Все / Лоты / Жилые комплексы», сортировка, удаление, очистка и отмена в течение 15 секунд. Поддерживается синхронизация вкладок одного origin.
- Пример по `?preview=1` содержит два исходных компонента библиотеки; демонстрационный лот `384721` не заявляется реальным предложением. Сохранение в этом режиме отключено.
- Релиз включает все 15 объектов актуального публичного каталога (12 ЖК и 3 лота) из `katalog-nedvizhimosti/objects.json`, плюс две помеченные демонстрационные карточки. Сердечко в хедере каталога ведёт на эту страницу; оба используют общий ключ localStorage. Для обновления данных нужно повторить экспорт из актуального каталога. Это статический архив, серверные аккаунты и синхронизация устройств не восстановлены.
- Меню и контактное окно используют native dialog: Escape, изоляция фокуса и возврат к кнопке. «Заказать звонок» и «Обратная связь» открывают доступные телефон/мессенджеры/email. Форма CRM и фиктивная отправка не добавлены.
- Фотографии примера и логотипы локальные. Для старых фотографий каталога, недоступных с HTTP 403, остаётся нейтральная заглушка.

## Проверка

`NODE_PATH=<путь к установленному Playwright> node tools/check-favorites.cjs` при работающем сервере 8018. Порт можно изменить через `BARNES_PREVIEW_URL`.

[Проверенный результат](verification.json): 320, 390, 540, 768, 1024, 1440, 1920 и 2560 px. Проверены сохранение и миграция ID, вкладки лотов/ЖК, сортировка через канонический dropdown, удаление/отмена, очистка/отмена, синхронизация вкладок, изоляция демонстрационного состояния, контактное окно, меню, Escape/возврат фокуса, загрузка фотографий/логотипов, отсутствие ошибок JS и горизонтального переполнения.

Типографика, размеры кнопок, фактов и SVG-сердечек дополнительно сопоставлены по computed styles с исходной карточкой, без стилей композиции страницы: `tools/favorites-reference.html` на 390 и 1440 px. Все перенесённые файлы сверены с SHA-256 источника.

Опубликовано на GitHub Pages по прямому поручению пользователя. На домен barn-estate.ru эта публикация не устанавливалась.
