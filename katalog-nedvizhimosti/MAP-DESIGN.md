Поручение: добавить узнаваемый значок открытия карты и перенести полноэкранный вид узла «Курортная»: список проектов слева, крестик, zoom и мобильную нижнюю панель. Показывать объекты именно текущей выдачи каталога.

Выбран перенос существующего интерфейса, как прямо попросил пользователь. Кнопка «На карте» с контурной иконкой сложенной карты находится у сортировки; на телефоне — рядом с избранным во второй строке. Новая inline-секция заняла бы место карточек, а другая библиотека карт изменила бы согласованный референс. Размещение кнопки — решение исполнителя.

Источник вида — `kurortnaya/js/map-fullscreen.js`, `css/map-fullscreen.css`, `assets/map-preview.png` текущего синхронизированного GitHub snapshot. Исходный CSS копируется локально с SHA. На исходном изображении вшиты курортные метки; оно заменено на чистый статичный снимок официального OpenStreetMap embed, без посторонних меток. Сохранены пояснение о статичном фоне и атрибуция OSM в изображении и интерфейсе. Геометрия панелей и управляющих элементов остаётся из курортной. В 37 записях каталога нет подтверждённых координат: точки не выдумываются, живой API не подключается. Список использует реальные названия, изображения, цены и ссылки объектов каталога.
