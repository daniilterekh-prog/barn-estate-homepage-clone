# Каталог недвижимости BARNES — публичное превью

[Открыть готовую страницу](https://daniilterekh-prog.github.io/barn-estate-homepage-clone/katalog-nedvizhimosti/).

Опубликовано по поручению пользователя 19.10.2026. Источник: `daniilterekh-prog/barnes-sites`, ветка `codex/catalog-listing-20261019`, commit `dfe321be05d8816f5d1052257cd3013c0635274d`.

Рабочая версия сохраняется в barnes-sites; эта папка — публичное GitHub Pages превью. Использован канонический BARNES UI-kit из barnes-assets, точные исходники и SHA — `kit-sources.json`. Два вида карточек, общий dropdown, подробные фильтры, поиск, сортировка, избранное.

15 сохранённых записей: 12 проектов и 3 вторичных лота. Актуальный API наличия и отправка заявок не подключены; неизвестные характеристики не выдумываются. На боевой домен BARNES страница не установлена.

Файлы самодостаточны: локальные CSS, JS, шрифты и изображения. Новые пакеты не нужны. Для локального просмотра запустить HTTP-сервер из корня репозитория.
