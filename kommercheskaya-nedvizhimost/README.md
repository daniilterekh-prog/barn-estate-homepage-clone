# Коммерческая — самодостаточная страница

Копируй всю папку: CSS, JS, изображения, SVG и шрифты находятся внутри.
Соседние разделы и установка npm-пакетов для запуска не нужны.

```text
index.html       страница и встроенные шаблоны
css/             все действующие стили
js/              действия, фильтры, карта, карусель, футер
assets/          изображения и SVG; source/ — исходные ассеты и шрифты
tools/           проверка изолированного пакета
verification/    отчёты и перечень удалённых файлов
STRUCTURE.md     структура и границы
```

Из этой папки запусти `python3 -m http.server 8793`, открой
http://127.0.0.1:8793/. Поддерживается также file://.
Проверка: `PLAYWRIGHT_PATH=/путь/к/playwright node tools/verify-package.cjs http://127.0.0.1:8793/`.
Используется установленный Chrome; CHROME_PATH позволяет переопределить путь.
Результат — verification/package.json.

Редактируй HTML в index.html, стили в css/, действия в js/. Динамические пути
JS рассчитываются от корня страницы; CSS url — от css/. Отдельная библиотека
превью блоков, как в курортной, здесь не создавалась.

Сохранены 12 исходных коммерческих лотов, цены, ID, ссылки и первые три объекта
в «Выборе BARNES». Карта — локальный снимок Москвы с исходной пустой выдачей;
zoom масштабирует изображение. API каталога и реальная отправка заявок не подключены.
Мессенджеры, карточки объектов и юридические документы намеренно внешние ссылки.

Старые версии удалены, а не спрятаны в папку архива. Перечень —
verification/cleanup.json; восстановление — через историю Git. Старые отчёты
в verification/ описывают исторические проверки; актуальный отчёт — package.json.

Основа: https://front.barnes.vsavr.ru/kommercheskaya-nedvizhimost/.
Дизайн компонентов — курортная этого репозитория. Канонические ассеты:
https://github.com/daniilterekh-prog/barnes-assets.
Происхождение фона — assets/cta-alina-unified-v2.md.

существующие компоненты BARNES, новые библиотеки не добавлены.
