# Лендинг — курортная недвижимость

Самостоятельный адаптивный лендинг BARNES Moscow со своей страницей и локальными файлами.

Мобильная загрузка: `index.html` сначала получает `mobile.html`, затем запускает `ui-kit-runtime.js` только на окончательной разметке. Не запускать runtime до `document.open/write`: window-API сохраняются при замене документа, а элементы и обработчики исчезают. При ошибке получения mobile snapshot runtime запускается на fallback-разметке. Регрессия: `scripts/verify-kurort-mobile-bootstrap.cjs` — touch-эмуляция iPhone, быстрая загрузка, задержка 1500ms и HTTP503, открытие/закрытие фильтров из херо, листинга и карты.

Утверждённый референс узлов первой степени: [библиотека блоков и UI-контракт](reference-first-degree.md). Переносимые блоки хранятся отдельно в каноническом barnes-assets.

## Локальные варианты компонентов

### Способы связи в CTA

Общий ContactAction в `ui-kit.css` используется в центральном и нижнем CTA. Сохранены исходные SVG и двухрядная сетка BARNES; новых библиотек нет. Иконка и название занимают одинаковые внутренние колонки (`18px 4.8em`, mobile `20px 4.8em`, gap `8px`), поэтому MAX и Telegram не смещаются относительно соседей. Контракт: [ContactAction в barnes-assets](https://github.com/daniilterekh-prog/barnes-assets/blob/main/ui-kit/components/contact-action.md). Проверка: `node scripts/verify-kurort-cta-channels.cjs` при сервере на 8769; ширины 320/390/768/1024/1366/1440/1920/2560 px, геометрия обоих CTA и выбор MAX/Telegram.

### Выпадающие быстрые фильтры

Дополнение: `brand-filters.js/css` — нативные независимые чекбоксы «Выбор BARNES» и «Эксклюзив BARNES» под toolbar и в панели карты. Авторский компонент без новых зависимостей, Tilda Sans 17/19 px weight 300, box 20px, touch target ≥44px, hover/focus/checked только #8B1D25. Общий `BarnesFilters.brandFlags`: массив `selection`/`exclusive`, выбор синхронизирован, общий reset+apply и reset карты очищают его. Для карты адаптер объектов принимает `brandFlags`, оба включённых признака объединяются по OR. В текущем снимке признаки отсутствуют: не придумываем эксклюзивность, показываем уведомление и не меняем выдачу. Листинг остаётся демонстрационным, без API-фильтрации. Проверка: `scripts/verify-kurort-brand-filters.cjs`, 320/390/768/1440/2560 px, клавиатура, перенос, синхронизация, сброс и отдельные размеченные fixtures.

`quick-filters.js` и `quick-filters.css` подключают белый popover по фронту Курортной к четырём полям листинга: локация (4 направления), тип недвижимости (апартаменты, квартира, квартира в новостройке, пентхаус), стоимость (4 диапазона оригинала), спальни (1/2/3/более 3). Тип использует `propertyTypes`: `apartment`, `flat`, `new_build`, `penthouse`, общий с подробными фильтрами. Сохранены типографика и SVG-стиль кнопок; для типа добавлен контур здания. Все четыре быстрых фильтра равной ширины. Десктоп: четыре поля в ряд, планшет и мобильный: 2×2. Кнопка «Все фильтры» отдельно. Popup сохраняет исходные header/close/options/selected-mark; типографика по BARNES: Tilda Sans, пункты 17/19 px weight300, заголовок 17/19 px weight400, line-height1.3, minheight40; тень отключена согласно общему правилу, hover/selection бордовые. Один popup, выбор сразу закрывает его и сохраняет состояние через `BarnesFilters.patch`. Дополнительно есть вариант снятия выбора.

Локация/диапазоны синхронизируются с общим modal, спальни хранятся отдельным ключом `bedrooms` (`1`, `2`, `3`, `4+`), не подменяют исходное количество комнат (`roomsMin/Max`). Общий reset+apply очищает также спальни; закрытие modal отменяет только черновик. При открытии modal popover закрывается. API каталога/навигация на серверные filter-URL не имитируются. При прокрутке popup следует за кнопкой; при уходе кнопки с экрана/resize/внешнем клике закрывается. Arrow keys/Home/End, Enter/Space/Escape и возврат фокуса проверены. `scripts/verify-kurort-quick-filters.cjs`: 390/768/1440/2560, значения, синхронизация/reset, keyboard, outside click, границы viewport.

### Общие подробные фильтры

Дополнение панели карты: восстановлены «+ / −» — масштабирование статичного изображения от1× до3×, шаг0.25, пределы отключают соответствующую кнопку; повторное открытие карты сбрасывает масштаб. Это не географический zoom Яндекс API. Desktop кнопки справа вертикально под крестиком, mobile горизонтально рядом с крестиком, без пересечения нижней панели. Быстрые параметры дополнены локацией (Сочи/Анапа/Алтай/Архыз) и спальнями (1/2/3/4+), SVG22px и типографика листинга. Адаптер: `directions` и `bedrooms` — массивы допустимых значений у объекта/ЖК. Нет метаданных в snapshot — показано пояснение, параметр не меняет выдачу. Смешанный набор с известными данными фильтруется строго, неизвестные значения не выдумываются. Reset очищает новые поля. Тесты проверяют комбинацию локация+спальни на отдельной fixture.

Карточка ЖК в листинге сохраняет непустой адрес из данных и выводит его над названием с тем же классом/типографикой, что карточка лота. Для текущего демо Grand Hotel пустое поле заполнено адресом офиса продаж на объекте «Сочи, ул. Шоссейная, 9Б» — источник https://grand.marine-garden-sochi.ru/ (12.10.2026). Проверка: `scripts/verify-kurort-project-address.cjs`, 390/1440/2560, порядок элементов, отсутствие дублей и одинаковый стиль адреса с лотом. Не использовать этот демо-адрес для других ЖК.

В панели карты «Тип объекта» — `apartment`/`flat`/`penthouse` (апартаменты/квартира/пентхаус), отдельно переключатель «Новостройки / Вторичка». Независимые параметры адаптера: `item.propertyTypes` (массив типов помещений) и `item.market` (`new-build` или `secondary`). Существующее `item.type=rc` обозначает карточку ЖК, не тип помещения и не рынок продажи. В снимке32 ЖК эти признаки неизвестны, не придуманы: при выборе недоступного параметра отображается пояснение, этот параметр не меняет выдачу. При наличии метаданных фильтры работают совместно; неизвестные записи не включаются в ограниченный результат. Повторный клик рынка снимает выбор; reset очищает оба. Тест проверяет комбинации на отдельной управляемой fixture, не подменяет production snapshot.

Карта открывает белый `hero-filter-modal--drawer` справа, по фронту Курортной (12.10.2026): ширина `min(520px, 100% - 420px)`, высота карты, header 76px / padding24-28-21, body24-28-16, footer18-28-22 с двумя кнопками46px. Заголовок24/400, группы14/400, checkbox-значения18/300, поля18/300. На mobile ≤540 панель занимает весь экран, отступы20px, типы в две колонки. Тип и ценовые диапазоны — светлые checkbox, не тёмные chips. В херо/листинге сохранён тёмный центральный modal. Одна форма и один state, без дублирования полей; закрытие панели оставляет карту открытой. Исходная тень отключена, hover/checked только бордо. Проверка дополнительно покрывает правую привязку, белый фон, размеры и восстановление dark-режима при следующем открытии из херо.

`filters-template.js`, `filters-modal.js`, `filters-modal.css` — одно тёмное окно по https://front.barnes.vsavr.ru/kurortnaya/ (снимок 12.10.2026), открывается из херо, листинга и полноэкранной карты. Разметка/размеры оригинала сохранены, московские районы по согласованию заменены на Сочи/Анапу/Алтай/Архыз. Основной CSS-контракт — `source.css`, с его `data-v-*`. Изолированные поправки добавляют слой поверх карты, keyboard/focus/inert, валидацию диапазонов и только бордовый hover вместо жёлтого.

`window.BarnesFilters.getState()` возвращает применённый выбор; `barnes:filters-apply` на document передаёт независимую копию данных. Закрытие/Escape отменяет черновик, «Сбросить» очищает черновик, «Применить» сохраняет его для трёх точек входа в пределах текущей страницы. После перезагрузки выбор сбрасывается. Это общий UI фильтра: API полного каталога не подключён, выбор направления/комнат/площади/отделки не выдаётся за рабочую фильтрацию каталога. Нужен отдельный обработчик события для боевой выдачи. Локальные фильтры самой карты остаются самостоятельными; сортировка доступна прямо в панели карты.

Проверка: `scripts/verify-kurort-filters.cjs`, 390/1440/2560, три точки входа, сохранение/отмена/сброс, диапазоны, геометрия, вложение поверх карты и Tab/Escape. Окно desktop 640 px, фон #292929, заголовок 24 px, заголовки групп 18 px, на mobile — весь экран. Секреты, новые пакеты и API-ключи не добавлялись.

Фильтры полноэкранной карты согласованы с листингом: Tilda Sans 17 px / 300 (19 px от 1441 px), ink `#4F4D49`, линии `#E4E4E4`, wine `#8B1D25`, высота поля 58 px. SVG параметров 22×22 / stroke 1.35, стрелки 10×10 / border 1 px; иконка подробных фильтров скопирована из листинга (18 px desktop, 22 px mobile / stroke 1.15). Подписи контролов однострочные, с доступными именами, без мелкого верхнего дубля. Собственный select-chevron заменяет системную стрелку. Поиск, цена, тип и сортировка не меняют свою семантику.

- `listing-mode.css` и `listing-mode.js` — переключатель, фильтры и карточка каталога.
- `map-fullscreen.js`, `map-fullscreen.css`, `map-projects.js`, `map-preview.png` — самостоятельная полноэкранная оболочка карты. Источник интерфейса и публичных данных: https://front.barnes.vsavr.ru/kurortnaya/, снимок 12.10.2026. На desktop панель 420px, на mobile раскрываемый нижний список. Поиск по названию, тип объекта, верхняя граница цены, сортировка и сброс работают локально по 32 объектам снимка. Неизвестные цены не попадают в ограниченный ценой результат. Подложка Яндекс статична, маркеры не реагируют на фильтрацию; zoom, геопоиск и API карты не подключены. Компонент не выдаёт это за интерактивную карту. Не использовать снимок каталога как актуальную базу; для боевого подключения заменить адаптер `window.BarnesMapProjects` и подложку.

- `start-sales-cards.css` и `start-sales-cards.js` — кинематографичные карточки только для блока «Старты продаж». Скрипт сохраняет существующий слайдер, реальные данные и ссылки из снимка страницы, а избранное синхронизирует между оригиналами и клонами слайдов через `localStorage`.
