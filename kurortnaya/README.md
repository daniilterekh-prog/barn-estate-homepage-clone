# Лендинг — курортная недвижимость

Самостоятельный адаптивный лендинг BARNES Moscow со своей страницей и локальными файлами.

Утверждённый референс узлов первой степени: [библиотека блоков и UI-контракт](reference-first-degree.md). Переносимые блоки хранятся отдельно в каноническом barnes-assets.

## Локальные варианты компонентов

- `listing-mode.css` и `listing-mode.js` — переключатель, фильтры и карточка каталога.
- `start-sales-cards.css` и `start-sales-cards.js` — кинематографичные карточки только для блока «Старты продаж». Скрипт сохраняет существующий слайдер, реальные данные и ссылки из снимка страницы, а избранное синхронизирует между оригиналами и клонами слайдов через `localStorage`.
