# Лендинг — курортная недвижимость

Самостоятельный адаптивный лендинг BARNES Moscow со своей страницей и локальными файлами.

Утверждённый референс узлов первой степени: [библиотека блоков и UI-контракт](reference-first-degree.md). Переносимые блоки хранятся отдельно в каноническом barnes-assets.

## Локальные варианты компонентов

### Выпадающие быстрые фильтры

`quick-filters.js` и `quick-filters.css` подключают белый popover по фронту Курортной к четырём полям листинга: локация (4 направления), тип недвижимости (апартаменты, квартира, квартира в новостройке, пентхаус), стоимость (4 диапазона оригинала), спальни (1/2/3/более 3). Тип использует `propertyTypes`: `apartment`, `flat`, `new_build`, `penthouse`, общий с подробными фильтрами. Сохранены типографика и SVG-стиль кнопок; для типа добавлен контур здания. Все четыре быстрых фильтра равной ширины. Десктоп: четыре поля в ряд, планшет и мобильный: 2×2. Кнопка «Все фильтры» отдельно. Popup повторяет исходные header/close/options/selected-mark и compact размеры source.css; тень отключена согласно общему правилу, hover/selection бордовые. Один popup, выбор сразу закрывает его и сохраняет состояние через `BarnesFilters.patch`. Дополнительно есть вариант снятия выбора.

Локация/диапазоны синхронизируются с общим modal, спальни хранятся отдельным ключом `bedrooms` (`1`, `2`, `3`, `4+`), не подменяют исходное количество комнат (`roomsMin/Max`). Общий reset+apply очищает также спальни; закрытие modal отменяет только черновик. При открытии modal popover закрывается. API каталога/навигация на серверные filter-URL не имитируются. При прокрутке popup следует за кнопкой; при уходе кнопки с экрана/resize/внешнем клике закрывается. Arrow keys/Home/End, Enter/Space/Escape и возврат фокуса проверены. `scripts/verify-kurort-quick-filters.cjs`: 390/768/1440/2560, значения, синхронизация/reset, keyboard, outside click, границы viewport.

### Общие подробные фильтры

`filters-template.js`, `filters-modal.js`, `filters-modal.css` — одно тёмное окно по https://front.barnes.vsavr.ru/kurortnaya/ (снимок 12.10.2026), открывается из херо, листинга и полноэкранной карты. Разметка/размеры оригинала сохранены, московские районы по согласованию заменены на Сочи/Анапу/Алтай/Архыз. Основной CSS-контракт — `source.css`, с его `data-v-*`. Изолированные поправки добавляют слой поверх карты, keyboard/focus/inert, валидацию диапазонов и только бордовый hover вместо жёлтого.

`window.BarnesFilters.getState()` возвращает применённый выбор; `barnes:filters-apply` на document передаёт независимую копию данных. Закрытие/Escape отменяет черновик, «Сбросить» очищает черновик, «Применить» сохраняет его для трёх точек входа в пределах текущей страницы. После перезагрузки выбор сбрасывается. Это общий UI фильтра: API полного каталога не подключён, выбор направления/комнат/площади/отделки не выдаётся за рабочую фильтрацию каталога. Нужен отдельный обработчик события для боевой выдачи. Локальные фильтры самой карты остаются самостоятельными; сортировка доступна прямо в панели карты.

Проверка: `scripts/verify-kurort-filters.cjs`, 390/1440/2560, три точки входа, сохранение/отмена/сброс, диапазоны, геометрия, вложение поверх карты и Tab/Escape. Окно desktop 640 px, фон #292929, заголовок 24 px, заголовки групп 18 px, на mobile — весь экран. Секреты, новые пакеты и API-ключи не добавлялись.

Фильтры полноэкранной карты согласованы с листингом: Tilda Sans 17 px / 300 (19 px от 1441 px), ink `#4F4D49`, линии `#E4E4E4`, wine `#8B1D25`, высота поля 58 px. SVG параметров 22×22 / stroke 1.35, стрелки 10×10 / border 1 px; иконка подробных фильтров скопирована из листинга (18 px desktop, 22 px mobile / stroke 1.15). Подписи контролов однострочные, с доступными именами, без мелкого верхнего дубля. Собственный select-chevron заменяет системную стрелку. Поиск, цена, тип и сортировка не меняют свою семантику.

- `listing-mode.css` и `listing-mode.js` — переключатель, фильтры и карточка каталога.
- `map-fullscreen.js`, `map-fullscreen.css`, `map-projects.js`, `map-preview.png` — самостоятельная полноэкранная оболочка карты. Источник интерфейса и публичных данных: https://front.barnes.vsavr.ru/kurortnaya/, снимок 12.10.2026. На desktop панель 420px, на mobile раскрываемый нижний список. Поиск по названию, тип объекта, верхняя граница цены, сортировка и сброс работают локально по 32 объектам снимка. Неизвестные цены не попадают в ограниченный ценой результат. Подложка Яндекс статична, маркеры не реагируют на фильтрацию; zoom, геопоиск и API карты не подключены. Компонент не выдаёт это за интерактивную карту. Не использовать снимок каталога как актуальную базу; для боевого подключения заменить адаптер `window.BarnesMapProjects` и подложку.
- Проверка оболочки: запустить HTTP-сервер на 8769 и `node scripts/verify-kurort-map.cjs` (Playwright из существующего web-capture-toolkit, путь можно задать через `PLAYWRIGHT_PATH`). Проверены desktop/mobile/wide, поиск, цена, сброс, закрытие и возврат фокуса. Новых пакетов нет.
- `start-sales-cards.css` и `start-sales-cards.js` — кинематографичные карточки только для блока «Старты продаж». Скрипт сохраняет существующий слайдер, реальные данные и ссылки из снимка страницы, а избранное синхронизирует между оригиналами и клонами слайдов через `localStorage`.
