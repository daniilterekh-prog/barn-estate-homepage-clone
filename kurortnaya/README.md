# Лендинг — курортная недвижимость

Самостоятельный адаптивный лендинг BARNES Moscow со своей страницей и локальными файлами.

Утверждённый референс узлов первой степени: [библиотека блоков и UI-контракт](reference-first-degree.md). Переносимые блоки хранятся отдельно в каноническом barnes-assets.

## Локальные варианты компонентов

- `listing-mode.css` и `listing-mode.js` — переключатель, фильтры и карточка каталога.
- `map-fullscreen.js`, `map-fullscreen.css`, `map-projects.js`, `map-preview.png` — самостоятельная полноэкранная оболочка карты. Источник интерфейса и публичных данных: https://front.barnes.vsavr.ru/kurortnaya/, снимок 12.10.2026. На desktop панель 420px, на mobile раскрываемый нижний список. Поиск по названию, тип объекта, верхняя граница цены, сортировка и сброс работают локально по 32 объектам снимка. Неизвестные цены не попадают в ограниченный ценой результат. Подложка Яндекс статична, маркеры не реагируют на фильтрацию; zoom, геопоиск и API карты не подключены. Компонент не выдаёт это за интерактивную карту. Не использовать снимок каталога как актуальную базу; для боевого подключения заменить адаптер `window.BarnesMapProjects` и подложку.
- Проверка оболочки: запустить HTTP-сервер на 8769 и `node scripts/verify-kurort-map.cjs` (Playwright из существующего web-capture-toolkit, путь можно задать через `PLAYWRIGHT_PATH`). Проверены desktop/mobile/wide, поиск, цена, сброс, закрытие и возврат фокуса. Новых пакетов нет.
- `start-sales-cards.css` и `start-sales-cards.js` — кинематографичные карточки только для блока «Старты продаж». Скрипт сохраняет существующий слайдер, реальные данные и ссылки из снимка страницы, а избранное синхронизирует между оригиналами и клонами слайдов через `localStorage`.
