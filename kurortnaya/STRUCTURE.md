# Самодостаточный узел «Курортная»

План согласован запросом пользователя 12.10.2026. Основа — актуальная страница GitHub; визуальный дизайн и поведение не пересоздаются.

1. `index.html` и `mobile.html` остаются точками входа целой страницы.
2. `css/` и `js/` содержат только подключённые слои страницы; загрузчик, порядок CSS и мобильный документ сохраняются.
3. `assets/` содержит используемые изображения, SVG, шрифты и статичную подложку Яндекс. Нет зависимостей от соседних папок сайта или внешнего хостинга изображений.
4. `blocks/` — актуальная каноническая коллекция из barnes-assets: 15 секций, 3 карточки, фильтры и панель карты, фрагменты desktop/mobile, CSS, runtime, manifest и самостоятельные HTTP-превью. Общие ресурсы блоков не дублируются: пути ведут к ресурсам внутри узла.
5. `tools/` и `verification/` — воспроизводимая проверка переносимости и браузерный отчёт. README объясняет изменение блоков и подключение к боевому API.
6. Удаляются только неподключённые старые CSS/JS, экспериментальный card-lab, заменённые изображения и данные неиспользуемого vendor-runtime. Общие файлы других страниц не удаляются. История Git сохраняет прежние версии.

Проверки: перенос одной папки на отдельный HTTP-сервер, отсутствие внешних render-зависимостей/404/JS-ошибок, desktop/mobile/2560 px, изображения и шрифты, фильтры и sorting, полный экран карты и возврат, CTA/попап, все самостоятельные превью блоков. После проверок — commit + push и проверка опубликованной страницы.

Статичная карта не является работающим API Яндекс; ссылки, телефон и внешние переходы намеренно остаются внешними. Отправка формы и реальная выдача требуют backend.
