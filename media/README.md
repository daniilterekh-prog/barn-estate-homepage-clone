UI-кит главной BARN Estate v1.0.0 применён к отступам, сетке, типографике, кнопкам и контактам хедера. Экспорт проверенной страницы из приватного `barnes-sites/main-site/pages/media`, 03.11.2026. Полный проход по киту: 8 бровей, типографика, карточки, даты и отступы. Отдельный блок «Следите за рынком вместе с BARN Estate» удалён по указанию пользователя; подписка из hero ведёт к общей рассылке. Hero по странице продажи собственникам: направления под линией, крошки над крупным H1, обе CTA под описанием; на телефоне описание скрыто. В публикацию входят только файлы страницы, изображения и шрифты. Формы не отправляются. Исходники проверки и отчёты остаются в приватном репозитории.
