# Квиз зарубежной недвижимости · 01.11.2026

Согласованный сценарий: цель → страна → бюджет → контакты. Обращение в интерфейсе только на «вы».

- Цели: для жизни, для отдыха, для инвестиций, пока выбираю.
- Страны в точном порядке: Таиланд, ОАЭ, Грузия, Турция, Азербайджан, Другие страны. Это варианты запроса, не обещание наличия объектов в локальном каталоге.
- Бюджет/диапазон и ₽ / $ / €; предусмотрен ответ «Бюджет пока не определён».
- Telegram / WhatsApp / MAX / Звонок, имя и номер телефона; комментарий необязателен. Согласие не предвыбрано.
- Из общей кнопки открываются вопросы. Из карточки — сразу контакт с названием/ссылкой/страной объекта и выбранным звонком. Эксперт — Денис Перковский.

Основа дизайна — утверждённый [UI-kit v1.0.0](https://github.com/daniilterekh-prog/barnes-sites/blob/barn-estate-home-reference-v1.0.0/main-site/pages/home/exact-2026-10-21/UI-KIT.md), `exact-2026-10-21/home-owner-form.css` и контактные роли `home-buttons.css` из текущей главной. Руслан, ветки продажи/аренды/партнёрства и московские направления не копируются. Существующий портрет Дениса остаётся локальным.

Реализация: `blocks/international-quiz/template.html`, `css/international-quiz.css`, `js/international-quiz.js`. Сборка включает template и подключения через `tools/build-page.cjs`. Остальные несогласованные изменения из UI-аудита в этот этап не входят.

Проверки: порядок стран, обязательность выбора/валидация, бюджет и валюта при возврате, сохранение объекта, все каналы/точки входа, фиксированная рамка на шагах, клавиатура/Escape/возврат фокуса/inert, размеры320–2560px и низкий landscape. Отдельно — сохранность фильтров/карты и автономности папки. Нет отправки в CRM: валидная заявка не выдаётся за доставленную. Персональные данные не сохраняются в localStorage и не пишутся в отчёт.
