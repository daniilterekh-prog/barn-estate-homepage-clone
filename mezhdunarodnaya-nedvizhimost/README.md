# Зарубежная — самодостаточный узел BARNES

Копируй всю эту папку: для страницы не нужны соседние разделы сайта, внешний хостинг изображений или npm-пакеты. Оформление и поведение сохранены; зарубежные данные — 4 проекта и 12 лотов.

```text
index.html, mobile.html    актуальная адаптивная страница
css/                      только подключённые стили + общий header
js/                       действующее поведение, локальные состояния карты
assets/                   изображения, SVG, fonts/, imported/
blocks/                   13 редактируемых исходников секций
templates/                каркас страницы и белые фильтры карты
tools/                    сборка, проверка переносимости, dry-run очистки
verification/             актуальные отчёты структуры и проверки
standalone/index.html     совместимый переход на актуальную страницу
```

## Открыть и изменить

Из этой папки: `python3 -m http.server 8126`, затем `http://127.0.0.1:8126/`. Для мобильного входа — `/mobile.html`; адаптивность одинакова, отдельной устаревшей версии нет. Используй HTTP, не `file://`.

Исходники секций находятся в `blocks/<название>/page.html`, общая оболочка — `templates/page.html`. После изменения:

```sh
node tools/build-page.cjs
node tools/build-page.cjs --check
```

Собранные `index.html`/`mobile.html` не редактируй отдельно. `blocks/` — исходники этой зарубежной страницы до выполнения JS, не импортированная база курортных объектов и не независимые виджеты. Пути `assets/...` в них рассчитываются от корня целой страницы.

Хэдер после hero создаётся `js/node-components.js`; карточки/характеристики и переключатель рынка — `js/node-catalog.js`. Фильтры, сортировка, FAQ/слайдеры — `js/source-runtime.js`, `js/node-quick-filters.js`, `js/node-brand-filters.js`. Полноэкранная карта — `js/node-map-browser.js`, её белая панель редактируется в `templates/map-filters.html` и включается сборщиком. Действующие стили — одноимённые файлы в `css/`.

## Квиз зарубежной недвижимости · 01.11.2026

[Сценарий и контракт](QUIZ.md). Общие CTA, закреплённый хедер, футер и плавающий эксперт открывают цель → страну → бюджет → контакты; кнопка карточки — сразу контакты с объектом. Поиск «Найти» остаётся поиском. Эксперт — Денис Перковский; вопросы только на «вы». Страны: Таиланд / ОАЭ / Грузия / Турция / Азербайджан / Другие страны. Они не меняют ассортимент сохранённого каталога.

Исходники: `blocks/international-quiz/template.html`, `js/international-quiz.js`, `css/international-quiz.css`. Дизайн унаследован от утверждённого [UI-kit v1.0.0 главной](https://github.com/daniilterekh-prog/barnes-sites/blob/barn-estate-home-reference-v1.0.0/main-site/pages/home/exact-2026-10-21/UI-KIT.md); CSS-основа `exact-2026-10-21/home-owner-form.css`, финальные роли кнопок — `home-buttons.css` (1px/400;64px desktop,58px mobile). Унаследованные селекторы модалки изолированы; соседние страницы не изменяются. Новых библиотек нет.

Ответы и выбранная валюта сохраняются при переходах назад; имя и телефон из inline-CTA предварительно подставляются. Согласие всегда требуется явно. Комментарий необязателен. Клавиатура, Escape, удержание/возврат фокуса и `inert` поддерживаются. При видимой кнопке футера плавающий эксперт скрывается, чтобы не перекрывать вход в квиз.

Проверка: `PLAYWRIGHT_PATH=/путь/к/playwright node tools/verify-quiz.cjs [URL]`; отчёт `verification/quiz.json`. Серверная отправка не подключена. Валидная форма показывает «Данные не отправлены», не делает POST и не сохраняет персональные данные в браузерное хранилище. Для будущего адаптера предусмотрено событие `barn:lead` с `detail.form/data/status=preview`; само событие не подтверждает доставку заявки.

Уже использовавшийся SVG логотипа сохранён как `assets/brand-logo.svg` из канонического `barnes-assets/brand/barn-estate/logo.svg`: меняется только путь, не изображение, чтобы не нарушить автономность пакета.

## Проверка и очистка

`node tools/verify-package.cjs http://127.0.0.1:8126/` проверяет папку, обслуживаемую отдельно: два входа, 8 ширин, изображения/шрифты, отсутствие 404/JS-ошибок/внешних render-зависимостей, фильтры/рынок/карта/CTA/FAQ. Playwright задаётся через `PLAYWRIGHT_PATH`, используется установленный Chrome. Отчёт — `verification/package.json`. Сборка проверяется `tools/build-page.cjs --check`.

`node tools/clean-unused.cjs` — только dry-run. После ручной проверки списка `--apply` удаляет неподключённые ресурсы. Текущая очистка записана в `verification/cleanup.json`; старые снимки, отчёты, версии CSS/JS и изображения можно восстановить из истории Git. Соседние страницы не затронуты. Старый путь `standalone/` сохранён без дублирования ресурсов.

## Сохранённые решения и ограничения

- Присланный desktop hero — 1920×526; mobile `hero-mobile-villa.png` — 941×1672. До 540 px выбирается мобильная картинка. Файлы не изменялись.
- Над названием карточек — страна; в характеристике проекта «Локация» остаётся город. Быстрые фильтры называются «Страна / Тип / Стоимость / Спальни». Названия каталога/карты — одна строка с троеточием, полный текст сохранён в данных.
- В свёрнутой карте нет значка фильтров. Полный фильтр доступен из hero, листинга и справа полноэкранной карты на белом фоне. Рынок обязателен и синхронизируется между списками.
- Карта — локальные снимки/тайлы, не живой API Яндекс; публичные API-параметры удалены из render-ресурсов. Поиск ограничен сохранёнными карточками. Неизвестные брендовые метки/типы/спальни не выдумываются.
- Телефон, мессенджеры, политики и ссылки объектов намеренно внешние. CRM/реальная отправка заявок не подключены: форма не выдаёт ложного подтверждения доставки.
