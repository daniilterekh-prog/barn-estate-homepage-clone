Происхождение: копия prodazha_sobstvennikam из публичного commit 6e079b5056d4e07817c3ee2a5f500211755b684a; региональный референс — home-spb, commit0374ee92. GitHub Pages — рабочее превью с noindex,nofollow. На боевой домен СПб не установлено. Обработчик заявок и CRM не подключены; реальные данные не отправляются.
