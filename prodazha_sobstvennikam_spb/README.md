Вход — index.html. Изменяемые контроллеры изолированы в spb-*.js; отдельный spb.css дополняет существующий кит. Зависимости не устанавливались. Исходная московская страница и пять защищённых узлов не менялись.

Происхождение: копия prodazha_sobstvennikam из публичного commit 6e079b5056d4e07817c3ee2a5f500211755b684a; региональный референс — home-spb, commit0374ee92. Изображения уже использовались в главной СПб и сохраняют указанное там происхождение из barnes-assets. Файл SPB-SOURCE.json содержит ссылки и контрольные суммы.

GitHub Pages — рабочее превью с noindex,nofollow. На боевой домен СПб не установлено. Обработчик заявок и CRM не подключены; реальные данные не отправляются.

Блок «Направления BARN Estate» удалён вместе с пунктом меню. CTA использует непрерывный интерьерный фотофон из действующего блока консультации; новый портрет Людмилы с прозрачностью расположен справа. На телефоне — компактный портрет и форма на том же фоне.

## Новая серия изображений · 10.11.2026

По поручению пользователя сгенерированы и установлены 11 новых декоративных кадров: херо, шесть карточек презентации, панорама, стратегия, фон CTA и рассылка. Использован встроенный image_gen; оптимизация WebP и мобильные версии — установленный Sharp. [Оригиналы и точные промпты](https://github.com/daniilterekh-prog/barnes-assets/tree/main/owner-sale-spb/editorial) · [Карта применения и SHA-256](EDITORIAL-IMAGES.json).

Это художественные иллюстрации, не фото конкретных объектов и не планировки предложений. Недавно подготовленный портрет Людмилы и логотип сохранены. Общая библиотека компонентов и защищённые страницы не менялись.

Фон CTA и фотофон окна эксперта переведены в монохром на уровне CSS, чтобы сочетаться с чёрно-белым портретом Людмилы. Бордовые элементы формы сохраняют цвет; исходные иллюстрации остаются в канонической библиотеке.
