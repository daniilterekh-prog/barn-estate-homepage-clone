# Рассылка один в один с главной

Референс: home-spb и основная главная, публичный commit 2e198699. Разметка, иллюстрации, шрифты, размеры, отступы, кнопка и фон до краёв перенесены в отдельные файлы страницы собственников СПб. Общие зависимости не редактировались.

[Геометрия](geometry.json) совпала на 320, 390, 768, 1440, 1920 и 2560 px. [PNG](pixels.json) попарно идентичны по SHA-256 на всех шести ширинах; Pixelmatch — 0 разных пикселей при threshold 0.1. Для сравнения блок закреплён на целой координате, внешние шапка/футер/виджет скрыты; размеры сначала сняты в обычном потоке. Снимки ниже сохранены в WebP после проверки PNG.

[Email и клавиатура](form.json): неверный адрес отклоняется, фокус остаётся в поле; Tab переводит на кнопку. Валидный адрес показывает статус превью без реальной подписки и POST-запросов. [Регрессия страницы](regional-regression.json) прошла на шести ширинах, штатные 5 unittest и node --check — без ошибок.

[Публикация и повторная сверка живой страницы](live.json): 390/1440 px, PNG совпадают с главной побайтно.
