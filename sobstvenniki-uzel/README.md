## Структура

1. Первый экран «Услуги собственникам недвижимости» и консультация.
2. Четыре услуги: продажа городской, загородной и коммерческой недвижимости, аренда.
3. Существующий блок преимуществ с четырьмя вкладками.
4. Пять этапов из ТЗ в текущем слайдере карточек.
5. Существующий CTA стратегии и полный футер.

По прямому ответу пользователя 11.11.2026 загородная и коммерческая карточки временно ведут на общую страницу продажи. Городская ведёт на продажу, аренда — на текущую страницу аренды. Статьи и FAQ не добавлены: в ТЗ они оставлены открытыми вопросами. Разделы, относящиеся только к продаже, и email-подписка убраны из этой страницы.

## UI-кит и файлы

- `index.html` — полная страница; основные услуги присутствуют в исходном HTML.
- `owner-sale.js` — локальный контроллер страницы: навигация, пять этапов, слайдер и адаптивный хедер.
- `owner-hub.css` — только пояснения фотокарточек, фокус, reduced motion и затемнение новых фотокарточек. Размеры текста и интервалы берутся из существующих CSS-переменных кита.
- `page-kit.css`, `media-reference.css`, `hero.css`, `hero-laptop.css`, базовые CSS и дизайн хедера/футера сохранены без изменений.
- `_site/` — собственные зависимости этой страницы; общие файлы других страниц не меняются.
- Форма эксперта поддерживает продажу и аренду; валидация, согласие, каналы связи, Escape и возврат фокуса сохранены. В превью заявки не отправляются; интерфейс прямо сообщает об этом.

Стек: существующий HTML/CSS/JavaScript BARN Estate; новых библиотек нет. Происхождение компонентов — текущая страница продажи и UI-кит главной, извлечённые в первоначальную копию 10.11.2026.

## Запуск и обновление

Запускать через HTTP из корня публичного репозитория, например `python3 -m http.server 8795`; адрес `/sobstvenniki-uzel/`. Публикация — штатный GitHub Pages workflow из `master` после тестов. Канонический runtime-пакет хранится в `barnes-sites/main-site/pages/owner-hub/`; экспортируется целиком в эту папку, без пересборки других страниц.
