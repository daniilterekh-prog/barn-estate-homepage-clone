# Собственники — загород

[Открыть страницу](https://daniilterekh-prog.github.io/barn-estate-homepage-clone/sobstvenniki-zagorod/) · [Исходники](https://github.com/daniilterekh-prog/barnes-sites/tree/main/main-site/pages/собственники%20загород).

Отдельная страница продажи загородной недвижимости BARN Estate. Постоянная папка названа пользователем; публичный адрес без кириллицы и пробелов.

## Текущее состояние ·13.11.2026

- 12 собственных загородных иллюстраций: первый экран, оценка объекта, стратегия, шесть преимуществ, панорама и публикация в журнале. [Оригиналы и оптимизированные изображения](https://github.com/daniilterekh-prog/barnes-assets/tree/main/owner-country/editorial) · [Промпты и контрольные суммы](assets/editorial/PROMPTS.json). Встроенный image_gen; WebP подготовлены Sharp без изменения сюжета. Это вымышленные сцены, не фотографии выставленных лотов.
- В CTA, всплывающей форме и виджете — исходное фото Михаила Долгова из действующего загородного узла. Его лицо не генерировалось. CTA повторяет композицию этого узла: эксперт слева, форма справа, текущие кнопки и отступы; тексты относятся к продаже дома.
- В шапке и футере — актуальный логотип BARN Estate из канонической библиотеки.
- Три перехода к другим услугам собственникам: продажа городской недвижимости, коммерческая продажа и аренда. Изображения скопированы из общего узла «Собственникам», внешние каталоги здесь больше не подставляются.
- Сохранены полное загородное наполнение, читаемое раскрытие карточек и локальные интервалы. Плавающая карточка не перекрывает форму во время ввода.

## Файлы и источники

`index.html` — полная страница. `country-cta.css` — изолированный перенос CTA действующего загородного узла; `country.css` и `country.js` — местные уточнения. `_site/` — замороженные зависимости UI-кита, общие файлы других страниц не меняются.

[ТЗ «Собственник загородная»](https://docs.google.com/document/d/10h2UBtZCoKiUJGEKvC43um7Xax_V-sTJ3soDRDN-2iY/edit?tab=t.r3ubibduiehj) · [Текстовое наполнение](COUNTRY-CONTENT.json) · [Происхождение файлов](COUNTRY-SOURCE.json) · [Решения и проверка](IMPLEMENTATION.md).

Стек: существующий HTML/CSS/vanilla JavaScript BARN Estate. Сохранён UI-кит и правила frontend-памятки; новые библиотеки и аккаунты не добавлены. Запуск: `python3 -m http.server 8000` из этой папки.

## Границы

GitHub Pages — статическое превью с `noindex, nofollow`. Заявки и подписка не отправляются; интерфейс сообщает об этом. CMS, CRM и рабочий домен не изменялись. Сбой обновления фотографий из CMS остаётся задачей разработчиков оригинального сайта. Пять финальных узлов, общий узел «Собственникам» и исходная страница продажи не менялись.
