# Общий шаблон лота · BARN Estate

[Открыть GitHub Pages](https://daniilterekh-prog.github.io/barn-estate-homepage-clone/stranitsa-lota/).

Публичный пакет актуального общего шаблона от01.11.2026. Источник: `daniilterekh-prog/barnes-sites`, `main-site/pages/lot/`, commit `b80dd67`. Это один тип страницы для всех лотов, а не отдельная папка объекта.

Перенесены утверждённый UI-кит главной v1.0.0, сетка, типографика и кнопки, готовые хедер/рассылка/футер. Происхождение общих блоков и SHA ассетов — `kit/provenance.json`; версия референса — `barn-estate-home-reference-v1.0.0`. Шрифт — Tilda Sans. Новые библиотеки не устанавливались. SVG звонка — Material Icons, Apache-2.0, лицензия в `kit/assets/`.

Фото, цена, галерея, характеристики и брокер принадлежат выбранному лоту. Демонстрационные данные588036 сохранены12.10.2026, не являются подтверждением текущей цены/наличия. Для другого объекта поставщик задаёт `window.BARNES_LOT_DATA` до `lot-data.js`. Обязательны `id`, `title`, `cover.src`; описание и характеристики — `descriptionParagraphs`, `facts`; планировка — `floorPlan`; подтверждённый дом — `building.verified`; реальные альтернативы — `related`. Нет данных — нет фиктивного блока.

Нет больших повторяющихся секций ЖК/застройщика/стройки, нет тестовых ипотечных ставок. Подробная информация о ЖК должна находиться на отдельной странице. Общий квиз главной не заменяет запись на просмотр конкретного объекта.

Формы в этом превью не отправляют заявки и не подключены к CRM/рассылке. Они показывают честный локальный статус. Главная и другие страницы экспортом этого пакета не менялись. Публикация здесь не является установкой на рабочий домен BARN Estate.

Проверки исходника:12ширин320–3840px, меню/контакты/галерея/формы/Escape; дополнительно7ширин и3варианта данных. Старые `verification.json`, `interaction-verification.json`, `data-binding-verification.json` и PLAN относятся к пиксельной копии до переработки структуры и оформления, не к текущей версии. Права на исходные фотографии и материалы сохраняются у правообладателей.
