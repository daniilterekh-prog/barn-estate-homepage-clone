# Общий шаблон карточки лота BARNES

Эта папка — **тип страницы** общего сайта, как `stranitsa-zhk/`, а не отдельный пентхаус или новый сайт. Все карточки лотов используют одну разметку, одни стили и одно поведение. Новые папки с копиями по ID не создаются.

## Шаблон и данные

- `index.html` — общий каркас и исходные адаптивные стили карточки.
- `lot-template.js` — заполнение каркаса данными выбранного объекта, включая галерею и диалоги.
- `lot-data.js` — **демонстрационные данные** объекта 588036, использованного как визуальный референс. Для другого объекта поставщик данных задаёт `window.BARNES_LOT_DATA` перед загрузкой этого файла. Пример не перезаписывает переданные данные.
- `local.js` / `local.css` — общее поведение меню, галереи, отзывов, форм, карты и ипотеки.
- `source-data.js` — общие состояния меню и отзывов. Карта и её маркеры принадлежат данным лота, а не общему шаблону.
- `assets/source/` — локальные ресурсы эталонного наполнения. Другой лот использует свои ссылки на изображения, сохраняя общую вёрстку.

Обязательные поля: `id`, `title`, `cover.src`. Основные данные: `description`, `priceRub`/`displayPrice`, `broker`, `highlights`, `badges`, `gallery`. Метаданные задаются через `seo`; старые структурированные данные не переносятся на другой лот автоматически.

Необязательные блоки: `complex`, `developer`, `construction`, `map`, `mortgage`. Если блока в данных нет, он не показывается. Не используются характеристики, застройщик или фотографии демонстрационного объекта как запасные данные для другого лота. Отсутствующая цена отображается как «Цена по запросу».

Данные выбираются **до инициализации страницы**. Маршрутизация публичных URL и получение данных из CRM/API — отдельный слой сайта: они не требуют размножения этого шаблона. CRM-отправка форм пока не подключена; локальная форма проверяет поля и показывает телефон выбранного брокера.

## Происхождение и проверка

Визуальный референс: https://front.barnes.vsavr.ru/vtorichnaya-nedvizhimost/588036/ (12 октября 2026). Библиотека `daniilterekh-prog/barnes-assets` проверена перед переносом; ресурсы данного примера получены с оригинала. Сохранены исходные CSS, SVG, шрифты, фотографии и атрибуция карты; манифест и SHA-256 находятся в `source-assets.json`. API-ключей нет. Карта локальная: поиск фильтрует сохранённые маркеры, масштабирование ограничено сохранёнными тайлами.

`verification.json` — строгий diff всей страницы с эталонным наполнением: 18 ширин от 320 до 2560 px, viewport высотой 900 px, Chrome, DPR 1, загруженные шрифты и изображения, одинаково отключённые анимации. Pixelmatch: threshold 0, includeAA true. `interaction-verification.json` — проверки действий и диалогов. `data-binding-verification.json` — подстановка другого набора данных в тот же шаблон и скрытие отсутствующих блоков.

Инструменты существующего [web-capture-toolkit](https://github.com/daniilterekh-prog/web-capture-toolkit): Playwright 1.64.0 (Apache-2.0), Pixelmatch 8.0.0 (ISC). UI-шаблоны сторонних библиотек не устанавливались. Права на исходные материалы сохраняются у правообладателей.

```sh
node scripts/capture-lot-reference.cjs /tmp/barnes-588036
node scripts/build-lot-template.cjs /tmp/barnes-588036
node scripts/verify-lot-template.cjs /tmp/barnes-588036
node scripts/check-lot-template-interactions.cjs /tmp/barnes-588036
node scripts/check-lot-data-binding.cjs
```

Старые отдельные копии 576683 и 588036 удалены из актуальной структуры. Их предыдущие версии доступны в истории Git.
