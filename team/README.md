# Команда BARN Estate

Новая автономная страница `/team/` по утверждённому UI-киту главной v1.0.3. [Веб-превью](https://daniilterekh-prog.github.io/barn-estate-homepage-clone/team/).

## Состав и решения · 09.11.2026

Первый экран → каталог из 27 сотрудников → контакты → вакансии → штатный футер. Фильтры: вся команда, руководство, городская, загородная, коммерческая, курортная и зарубежная, офис и поддержка. Без JavaScript все сотрудники остаются видимыми, фильтры скрыты. На телефоне одна карточка в ряду, на планшете две/три, на десктопе четыре. Страница и компоненты изолированы; финальные узлы и их shared-зависимости не меняются.

Источник имён, должностей и фотографий: https://barn-estate.ru/team/, проверено 09.11.2026. Имена сохранены буквально; английские должности переведены на русский. Группировка по направлениям — редакционное решение на основе должностей, не официальная оргструктура. Исходные должности и URL каждого портрета сохранены в `data/team.json`. Биографии, стаж и персональные контакты не добавлялись. Контактный телефон/email/адрес и ссылка вакансий взяты с исходной страницы.

## Дизайн и зависимости

- Основа: [UI-kit v1.0.3](https://github.com/daniilterekh-prog/barnes-sites/blob/main/main-site/pages/home/exact-2026-10-21/UI-KIT.md), Tilda Sans 300/400, бордовый `#8b1d25`, общие размеры секций/кнопок/полей.
- Хедер и футер: зафиксированные копии `main-site/handoff/current/home/html/{01-site-header,14-site-footer}.html` и соответствующего CSS на базе commit `d4ab833b`. Стили меню извлечены из `handoff/current/home/css/page.css`. Контроллер меню/контактов локальный, без Nuxt и глобальных перехватов.
- Карточки: геометрия и типографика team-member-card главной (434/587, нижний градиент, 24/27 px имена, 16/18 px роли; mobile 22/15 px); радиус 1 px по актуальным страницам.
- Фон hero: существующий `main-site/pages/media/pictures/mock/contacts-background.webp`, без генерации/изменения изображения. Портреты оригинальной страницы сохранены как WebP, качество 88, без ретуши.
- Новые библиотеки не устанавливались. Памятка frontend проверена; применены существующие компоненты, дополнительные UI-наборы не нужны. Шрифты и логотипы скопированы из утверждённого handoff.
- В превью `noindex,nofollow`. На рабочем домене страница не устанавливалась. Контактные действия — рабочие `tel:`/`mailto:` и ссылка вакансий, форм и имитации отправки нет.

## Файлы и проверка

`index.html`, `team.css`, `team.js`, `css/` — runtime; `assets/` — используемые изображения/шрифты; `data/team.json` — проверяемое происхождение контента. `verification/check.cjs` — Playwright-проверка адаптива, всех фильтров, меню, контактов и изображений; результат в `verification/report.json`. Запуск: `python3 -m http.server 8176 --directory main-site/pages/team`, затем `node main-site/pages/team/verification/check.cjs`. Playwright берётся из установленного Toolkit либо из `PLAYWRIGHT_MODULE`, без установки зависимостей проекта.

Экспорт выполняется копированием только этой автономной папки в `/team/` превью-репозитория; общий экспорт 13 страниц и синхронизация shared не запускаются. Это сохраняет изоляцию от финальных узлов.
