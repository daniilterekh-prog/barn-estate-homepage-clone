Отдельная самостоятельная папка: HTML, CSS, JS, фотографии, SVG и шрифты. Публикация09.11.2026 из [рабочих исходников и проверок](https://github.com/daniilterekh-prog/barnes-sites/tree/codex/vacancies-20261109/main-site/pages/vacancies), commit `61e9cec446264610e985235cc2f30218c045136b`. Побайтовый состав runtime зафиксирован в [SOURCE.json](SOURCE.json).

Содержание — по [старой странице вакансий](https://barn-estate.ru/vacancies/), оформление — действующий кит BARN Estate, hero — по страницам собственников. Три направления и кнопки отклика ведут на исходную страницу работодателя hh.ru. Hero использует тёплую генеративно обработанную общую фотографию команды с Google Drive, нижний CTA — канонические фон и портрет Руслана; [происхождение](assets/cta-provenance.json). Подобранные альтернативные фотографии и генерируемая концепция сохранены отдельно в [исходниках](https://github.com/daniilterekh-prog/barnes-sites/tree/codex/vacancies-20261109/main-site/pages/vacancies/references/team-photos) и здесь не подменяют утверждённую версию.

Это публичное превью: `noindex,nofollow`, canonical указывает на barn-estate.ru. Публикация на GitHub Pages не является установкой на боевой сайт. Общие зависимости и пять финальных узлов не изменялись.

Страница не требует сборки или внешних библиотек. Все необходимые ассеты находятся внутри этой папки. Для локального запуска: `python3 -m http.server 8819 --directory vacancies` из корня репозитория.
