# Правила правок Вавилова 64

- Перед изменением UI сверить актуальный `daniilterekh-prog/barnes-assets/ui-kit`
  и локальную карту контрактов `ui-kit-rules.md`.
- UI-kit имеет приоритет над произвольными эффектами дизайн-макета.
  Сначала сообщить о конфликте; новое исключение требует явного утверждения пользователя.
- Не добавлять смещения, повороты, масштабирование или смену рисунка стрелок CTA.
  Hover меняет только цвет/opacity, без изменения геометрии.
- Hero — две равноразмерные ActionButton как в амбассадорах: основная залитая,
  вторичная с белой рамкой. Не возвращать вторую кнопку к маленькой текстовой ссылке.
- В hero использовать статичные смысловые outline-иконки 24px viewBox/1.5px stroke:
  поиск лотов и документ презентации, оптические размеры 26/28/24px.
  Не добавлять туда диагональные или Unicode-стрелки.
- ActionButton, ContactAction, круглые контролы, текстовые CTA, FAQ и избранное
  проверяются по отдельным контрактам, не по общему селектору `button`.
- Сохранять утверждённые исключения: композицию «Архитектура», адрес над H1,
  mobile-height 520/560 px, одну mobile-CTA, неизменные хэдер и крошки.
- Высота hero как в амбассадорах: 900px desktop, 1040px wide ≥1441px,
  640px tablet 769–1024px. Не возвращать 100vh/100svh или vh-отступы.
- После правок выполнить `node --test vavilova-64/button-kit.test.cjs` из корня,
  проверить соответствующие breakpoint, hover, focus и состояния выбранного канала.
- Обновлять CSS/JS cache-version; проверенные изменения commit + push.
- Не заменять отсутствующий `#apartments` фиктивным списком или другой услугой.
- `#characteristics.vavilova-passport` — утверждённый вариант «Паспорт проекта»
  из пользовательского комплекта: локальные размеры имеют приоритет
  над общим ActionButton. Не переносить CTA из `.vp-footer` старым скриптом.
  Не подключать preview.css, новые шрифты или дополнительную форму.
- Последняя правка заменяет символ → у консультации в паспорте SVG-стрелкой
  кита: path M3 13 13 3M5 3h8v8, stroke 1.35, 14/16px, без анимации.
- Для паспорта дополнительно выполнять `node --test vavilova-64/passport.test.cjs`.
