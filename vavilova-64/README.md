## Выравнивание по странице амбассадоров

### Текущий hero: «01 — Архитектура»

Последовательность контента: крошки → адрес → название → параметры → действия.
Адрес перенесён над H1 на всех разрешениях; интервал до H1 20 px desktop,
15 px на 541–768 px и 14 px на телефоне. Высота hero сохранена.

При ширине ≤768 px в hero оставлена только кнопка «Смотреть лоты».
«Получить презентацию» скрыто и исключено из tab-order; на desktop оба действия сохранены.

Последующая правка: на ширине ≤540 px возвращена прежняя минимальная высота
520 px, на 541–768 px — 560 px; mobile не растягивается на 100svh.
Новое оформление и оба действия сохранены, desktop остаётся 100svh.

Последний слой `architecture-hero.css` и `architecture-hero.js` реализует
согласованное [ТЗ](architecture-hero-spec.md) от 12 октября 2026.
Исторические параметры hero ниже заменены этим слоем, но настройки хедера,
крошек и остальных секций сохранены. Height 100svh, крупный Tilda Sans H1,
видимые колонки характеристик, одна бордовая CTA и текстовый запрос презентации.
Источники: пользовательский дизайн «01 — Архитектура» и существующая фотография
`assets/reference/remote-01.jpg`; собственные CSS/JS, без новых зависимостей.
Проверки и ограничение отсутствующего списка лотов:
[architecture-hero-verification.md](architecture-hero-verification.md).

Hero: вместо крупного метража — компактная группа «Площадь / Цена / Сдача».
На desktop >1024 px: значения в строке через «·» без видимых подписей,
адрес и характеристики 18 px, кнопки через 28 px. Крошки 14 px,
интервалы крошки → H1 → адрес → характеристики: 20 / 12 / 16 px.

Цена пока «Цена по запросу». Правила отсутствующих данных:
