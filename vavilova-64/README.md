# Вавилова 64

Самостоятельная страница проекта. Карточки «Похожих проектов» адаптированы из
`../kurortnaya/start-sales-cards.css` и `../kurortnaya/start-sales-cards.js`
(локальный компонент BARNES, 12 октября 2026).

Используются исходные фото, названия, цены и ссылки проектов. Оформление перенесено
в `similar-project-cards.css`, преобразование разметки — в `similar-project-cards.js`.
Сетка страницы сохранена; высота карточки 438 px. Избранное использует общий ключ
`barnes-start-sales-favorites`, как в курортном разделе. Новые пакеты не добавлены.

## Выравнивание по странице амбассадоров

Hero: вместо крупного метража — компактная группа «Площадь / Цена / Сдача».
Цена пока «Цена по запросу». Правила отсутствующих данных:
[hero-data-rules.md](hero-data-rules.md). Используется собственная разметка
`dl/dt/dd` и существующий page-local CSS/JS, без новых библиотек.

Типографика FAQ сверена с `../for-partners/assets/faq-typography.css`:
H2 22/38/44 px и вопросы 18/20/22 px (≤1024 / 1025–1440 / ≥1441 px),
ответы 16 px при всех ширинах. Tilda Sans, вес 300/400/300;
межстрочный интервал 1.2/1.4/1.4. Правила изолированы внутри FAQ Вавилова.

`reference-alignment.css` и `reference-alignment.js` — отдельный слой, измеренный
по `../for-partners/` 12 октября 2026. Источник хедера и hero:
`../for-partners/assets/owner-shell.css`, `button-kit.css` и `for-partners.js`.

- Бровь над H2: 25 px desktop / 12 px mobile; пары собраны в общий контейнер.
- Заголовки добавлены в «О проекте» и галерею; бровь — над формой консультации.
- Основные мобильные секции: отступы 40 px сверху и снизу.
- Hero: 520/560/640/900/1040 px по брейкпоинтам референса; H1 весом 400.
- Крошки перед H1; desktop-кнопки в ряд, на телефоне одна основная кнопка.
- Desktop-хедер: четыре контакта-иконки, кнопка меню 44 px, поиск 24 px.
- Консультация в характеристиках остаётся после таблицы; исходные ссылки и
  фотографии проектов сохранены.

Проверка: 390, 768, 1440, 1920 px; все пары имеют нужный gap, изображения
загружены, горизонтального переполнения и ошибок JS нет. Один H1,
контактные ссылки подписаны, скрытая mobile-кнопка исключена из навигации.
