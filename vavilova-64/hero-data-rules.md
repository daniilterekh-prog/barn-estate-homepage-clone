# Правила характеристик в hero

Для отдельных страниц жилых комплексов BARNES. Согласовано 12 октября 2026.

## Данные и запасные формулировки

| Поле | Подтверждённые данные | Если данных нет |
| --- | --- | --- |
| Площадь | Диапазон, например «29–120 м²» | Не показывать параметр |
| Цена | Минимальная цена квартиры «от … млн ₽» | «Цена по запросу» |
| Сдача | Подтверждённый срок, например «III кв. 2029» | «Срок уточняется» |

- «Скоро в продаже» допустимо вместо цены только при подтверждённом статусе
  будущего старта продаж. Не выводить этот статус просто из отсутствия цены.
- Не подставлять нули, прочерки, выдуманные суммы, стоимость квадратного метра
  или пример стоимости из ипотечного калькулятора вместо минимальной цены квартиры.
- Не превращать неподтверждённые характеристики в факты. При противоречивых
  данных использовать запасную формулировку до уточнения.
- Цена «от» должна относиться к доступному предложению этого проекта;
  источник и дату проверки сохранять при обновлении данных.

## Отображение

Текущий вариант «01 — Архитектура» использует видимые подписи на всех
разрешениях и подпись «Стоимость» со значением «По запросу».
Точная актуальная типографика и размеры: [architecture-hero-spec.md](architecture-hero-spec.md).
Приведённые далее размеры относятся к предыдущему компактному варианту.

- Под адресом: компактная группа «Площадь / Цена / Сдача», без плашек.
- На desktop (>1024 px) значения собраны в одну строку через «·»:
  18 px, вес 300. Подписи визуально скрыты, но доступны скринридерам.
- При ширине ≤1024 px сохраняются колонки с подписями 12 px;
  значения 20 px на планшете и 16 px при ширине ≤768 px.
- На телефоне допускается перенос значения внутри колонки, но не выход
  за экран и не увеличение утверждённой высоты hero.
- Если остаётся одна или две характеристики, выводить только их:
  без пустых колонок и без растягивания значений ради заполнения пространства.
- При полном отсутствии полезных данных группу не показывать.
- Запасная формулировка — полноценное значение, а не пустая колонка.
