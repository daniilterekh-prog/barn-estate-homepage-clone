# Hero-хедер: разделы и счётчик — 02.11.2026

Поручение: добавить переходы на городскую, загородную, медиа и другие страницы; убрать квадрат у цифры3 возле сердца.

Причина: существующее меню создавалось из девяти колонок футера, но снимок CSS скрывал строку навигации до1280px включительно. Счётчик имел бордовую заливку, которая вместе с общим radius-cap превращалась в квадрат.

Исправлено в локальном home-kit.css: строка навигации отображается от1025px, компактный текст на1025–1200px, область нажатия ссылки min44px. При прокрутке сохранено сворачивание общего хедера; на телефоне/планшете — существующее раскрывающееся меню. У счётчика удалены фон, обводка, тень и внутренние поля, цифра остаётся у сердца. Исключения из radius≤1px не добавлялись.

В reference-interactions.js пять основных направлений ведут в соседние страницы превью: Москва/городская, загородная, коммерческая, курортная, зарубежная. URL вычисляется от текущего скрипта, поэтому префикс GitHub Pages сохраняется. Медиа, О BARN Estate, Собственникам и Санкт-Петербург сохраняют реальные внешние адреса: отсутствующие локальные страницы не выдумывались.

Проверка: `NODE_PATH=<runtime/node_modules> node vavilova-64/tools/verify-header.cjs [URL]`. Установленный Chrome и существующий Playwright, без новых зависимостей.

- 320,390,768,1024,1025,1100,1280,1440,2560px: девять пунктов, нужная видимость, нет горизонтальной прокрутки или обрезанных десктопных ссылок; фон счётчика прозрачный, border0, shadow none.
- Пять соседних страниц возвращают HTTP200; на городскую выполнен реальный переход по ссылке.
