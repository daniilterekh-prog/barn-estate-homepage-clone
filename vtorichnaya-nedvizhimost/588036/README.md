# BARNES — объект 588036

Самостоятельная копия страницы [пентхауса 588036](https://front.barnes.vsavr.ru/vtorichnaya-nedvizhimost/588036/). Открывается через `index.html` и через обычный HTTP-сервер. Соседние страницы и главная не меняются.

## Происхождение

- Оригинальные HTML, адаптивные CSS, SVG, шрифты и фотографии BARNES сохранены 12 октября 2026 года. Все используемые ресурсы находятся внутри этой папки; соответствия и SHA-256 — в `source-assets.json`.
- Каноническая библиотека [barnes-assets](https://github.com/daniilterekh-prog/barnes-assets) проверена перед переносом. Страницы 588036 в библиотеке не было, поэтому ресурсы взяты непосредственно с указанного оригинала.
- Меню, галерея с 38 фотографиями, просмотр карты, обратная связь, экскурсия, презентация, отслеживание цены и строительство используют исходную разметку и стили диалогов. Поведение реализовано в `local.js` без доменно-зависимого Nuxt-сервера.
- Карта использует сохранённые исходные тайлы, маркеры и стили Яндекса. Геометрия контрольных ширин сохранена отдельно; промежуточные размеры адаптируются относительно центра. Это локальный просмотр: поиск фильтрует сохранённые маркеры, масштабирование работает в пределах сохранённого изображения карты. Атрибуция Яндекса и ссылки на условия сохранены, API-ключи не включены.
- Формы сохраняют исходный внешний вид и локальную проверку полей. CRM/отправка заявок на оригинальный сайт не подключены; после проверки полей показывается контакт BARNES. Навигационные и юридические ссылки ведут на исходные адреса.

## Проверка

`verification.json` содержит строгий Pixelmatch-diff **всей страницы**, координаты секций и вычисленные параметры текста для ширин 320, 360, 390, 414, 540, 541, 640, 767, 768, 1024, 1025, 1280, 1281, 1440, 1441, 1600, 1920 и 2560 px при высоте viewport 900 px. Изображения декодированы, шрифты загружены, анимации отключены одинаково на оригинале и копии. Порог сравнения — 0, сглаживание включено в diff (`includeAA: true`).

`interaction-verification.json` содержит проверки основных действий на 390 и 1440 px и пиксельное сравнение семи десктопных состояний диалогов. Проверены Escape, галерея, раскрытие описания, отзывы, клавиатурное управление ипотекой, категории карты и валидация формы. Непроверенные комбинации браузера, DPR и размеров не объявляются побитно идентичными.

Инструменты из существующего [web-capture-toolkit](https://github.com/daniilterekh-prog/web-capture-toolkit): Playwright 1.64.0 (Apache-2.0), Pixelmatch 8.0.0 (ISC). Исходники UI не заменялись библиотечными шаблонами; использованы исходные компоненты BARNES. Перенос не меняет права правообладателей на исходные материалы.

Повторение проверки из корня репозитория:

```sh
# WEB_CAPTURE_TOOLKIT — checkout с установленными Playwright и Pixelmatch.
# CODEX_TOOLKIT_ROOT — существующий Toolkit с jsdom и pngjs.
node scripts/capture-property-588036.cjs /tmp/barnes-588036
node scripts/import-property-588036.cjs /tmp/barnes-588036
node scripts/verify-property-588036.cjs /tmp/barnes-588036
node scripts/check-property-588036-interactions.cjs /tmp/barnes-588036
```

`BARNES_RECAPTURE=1` принудительно обновляет уже существующие эталонные снимки. Перенос повторно импортирует только эту страницу.
