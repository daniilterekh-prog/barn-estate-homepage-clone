# Загородная недвижимость — узел первой степени

## Общий подробный фильтр

Иконка в херо, «Все фильтры» листинга и кнопка на карте открывают один `#catalog-hero-filters-panel`. Разметка окна сохранена отдельно в `country-filter-template.js` с оригинальной загородной страницы 12.10.2026; исходные scoped-стили уже присутствуют в `country-source.css`. `country-full-filters.js` добавляет открытие/закрытие, Escape, цикл Tab, возврат фокуса, сохранение применённых параметров и сброс. Диапазоны с минимумом выше максимума не применяются. В полноэкранном режиме карты окно переносится внутрь fullscreen-контейнера.

Цена и площадь фильтруют известные значения локального каталога. Тип объекта, район и количество комнат в сохранённых карточках не определены: спальни не выдаются за комнаты, классификации не придумываются; при выборе таких условий выводится пояснение. «Расширенный поиск» ведёт на исходный полный каталог BARNES. API оригинала и новая динамическая карта не подключены.

Проверка: `CAPTURE_TOOLKIT=/path/to/web-capture-toolkit node scripts/check-country-full-filters.mjs`. Восемь ширин 320–2560 px, три точки входа, клавиатура, применение цены, сохранение/сброс и валидация. Сравнение самого окна с оригиналом на 390/1440 px сохраняет и сырой pixel-diff, и diff непрозрачной области: desktop-скругления и внешний 1px край снимка исключаются, поскольку в них виден различающийся фон страниц. Это не сравнение страницы целиком.

CTA: блоки выбора канала ограничены теми же 610 px, что и поля формы. Регрессионная проверка `CAPTURE_TOOLKIT=/path/to/web-capture-toolkit node scripts/check-country-cta.mjs` проверяет оба CTA на 15 ширинах 320–2560 px: совпадение границ с формой, отсутствие обрезания кнопок и выбор MAX/Telegram мышью и клавиатурой. Правка изолирована в `country-node.css`, происхождение остальных компонентов не меняется.

## Текущий дизайн: утверждённая «Курортная»

По поручению пользователя от 12 октября 2026 года дизайн приведён к [опубликованному референсу `/kurortnaya/`](https://daniilterekh-prog.github.io/barn-estate-homepage-clone/kurortnaya/). Он заменяет прежнее требование повторять внешний вид исходного barn-estate.ru. Страница остаётся самостоятельным маршрутом `/zagorodnaya-nedvizhimost/`; главная и соседние страницы не изменяются.

Канонический контракт: [barnes-assets / FirstDegreeNode](https://github.com/daniilterekh-prog/barnes-assets/blob/main/ui-kit/first-degree.md). Локальные `ui-kit.css`, `listing-mode.css`, `start-sales-cards.css` и соответствующие runtime-файлы скопированы из актуального референса в этом репозитории; версии зафиксированы текущим коммитом, новые пакеты не установлены. Только существующий Splide 4.1.4 используется для новостей; блок стартов получает геометрию и управление из референса без второго конкурирующего движка. Мобильный шаг слайдов использует дробную реальную ширину, чтобы не накопить округление.

Перенесены типографика, брови/заголовки, вертикальные отступы, общий шаблон хедера и sticky-навигация, фильтры с нижними линиями, LaunchCard, ListingProject/ListingLot, CTA, FAQ, нижний блок и форма обращения. Локальные `country-node.css/js` адаптируют только загородные данные и обработчики. У карточек домов вместо квартирного этажа показан участок; неизвестные характеристики и сроки обозначены «По запросу», без выдуманных дат сдачи. Все 12 исходных лотов и 5 посёлков сохранены с фотографиями, ценами, ID и ссылками. Эксперт остаётся Михаилом Долговым, а не заменяется экспертом другого направления.

Каталог переключается между проектами и вторичной недвижимостью. Фильтрация, сортировка, мобильная дозагрузка, избранное, клавиатурное управление слайдером и открытие/закрытие формы проверяются локально. Форма не отправляет данные без backend-адаптера и не показывает фиктивное подтверждение успешной отправки. Карта сохраняет прежнее ограничение локального zoom-11 снимка; новый дизайн не подключает чужие API-ключи.

Актуальная проверка: `verification/node-reference-2026-10-12.json`. Запуск из корня репозитория:

```bash
CAPTURE_TOOLKIT=/path/to/web-capture-toolkit COUNTRY_LOCAL_URL=http://127.0.0.1:4188/zagorodnaya-nedvizhimost/ node scripts/check-country-node.mjs
```

Тест сравнивает реальные computed styles, отступы и размеры компонентов с опубликованным референсом, проверяет overflow, ошибки JavaScript, изображения, уникальность ID и пользовательские действия. Содержимое страниц различается: полностраничное равенство пикселей с «Курортной» не заявляется.

## Проверка и ограничения

Результаты измерений и строгого сравнения PNG: `verification/2026-10-12.json`. Одинаковая геометрия и computed styles не означают автоматического совпадения всех пикселей. Отчёт сохраняет реальные расхождения, а не округляет их до нуля.

Итог повторной сверки: на всех 20 контрольных ширинах полностраничные снимки и состояния прокрутки 0/700/1400 px совпали строго (0 отличающихся пикселей) **за пределами прямоугольника карты**. Неподменённые сравнения с картой также сохранены и содержат расхождения. Это исключение явно отражено в отчёте, а не скрыто общим процентом похожести.

Проверяются ширины 320–2560 px, включая границы 540/541, 560/561, 767/768/769, 1024/1025, 1280/1281 и 1440/1441. Рендер: Chrome, DPR 1, высота окна 900 px, reduced motion; изображения предварительно загружаются прокруткой всей страницы. Сравнение: Pixelmatch threshold 0, includeAA true. Это не доказательство совпадения на всех существующих устройствах, DPR или браузерах.

Карта пока является локальным снимком исходного zoom-11 вида с responsive UI, а не полноценной копией сервисного runtime. У оригинала масштаб и маркеры меняются после API-ответа, иногда до карты мира; локальная карта не воспроизводит эти динамические состояния, поиск и масштабирование. Меню/фильтры/серверная отправка форм также не подтверждены как полноценная копия оригинального backend. Поэтому статус всей страницы **не «100% pixel-perfect во всех состояниях»**.

Проверены раскрытие/сворачивание текста, SEO-ссылок и FAQ, переключение обеих каруселей; на HTTP и `file://` загружаются все три начертания шрифта, отсутствуют ошибки JavaScript и горизонтальное переполнение при 1440 px. Формы на оригинал не отправлялись.

## Повторить визуальную проверку

Из корня репозитория запустить `python3 -m http.server 4174 --bind 127.0.0.1`, затем:

```bash
CAPTURE_TOOLKIT=/path/to/web-capture-toolkit node scripts/audit-country-page.mjs
```

Используется существующий [web-capture-toolkit](https://github.com/daniilterekh-prog/web-capture-toolkit), Playwright 1.64.0 и Pixelmatch 8.0.0; новые зависимости проекта не устанавливаются. PNG и необработанный отчёт создаются во временной папке; исходная HTML-страница может содержать конфигурацию внешних сервисов, поэтому такие временные дампы не коммитятся.
