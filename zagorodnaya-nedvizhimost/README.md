# Загородная недвижимость — самодостаточная страница BARNES

Вся действующая страница находится внутри `zagorodnaya-nedvizhimost/`. Папку можно перенести отдельно: для оформления и работы интерфейса ей не нужны `../kurortnaya/`, `../shared/`, корневые `fonts/` или `pictures/`. Для запуска npm-пакеты устанавливать не нужно.

```text
zagorodnaya-nedvizhimost/
├── index.html       целая страница
├── css/             подключённые стили и локальный шаблон хедера
├── js/              данные страницы, фильтры, карусели и карта
├── assets/          действующие изображения, SVG, fonts/ и map/
├── vendor/          Splide 4.1.4 и его лицензия
├── tools/           проверка переносимости
├── verification/    актуальные результаты проверки и очистки
└── STRUCTURE.md     границы и решения по организации
```

## Открыть

Из этой папки запусти `python3 -m http.server 8786 --bind 127.0.0.1` и открой `http://127.0.0.1:8786/`. Лучше использовать HTTP: у `file://` другие правила для части возможностей браузера. Для GitHub Pages путь страницы остаётся `/zagorodnaya-nedvizhimost/`.

`index.html` — действующий HTML. Стили подключаются из `css/` в заданном порядке, скрипты — из `js/`; ресурсы JS вычисляют относительно адреса страницы, не каталога скрипта. Не менять порядок подключения без проверки: фильтры, карта и модальные окна зависят от него. Соседний узел `kurortnaya/` не является источником для этой страницы и не смешивается с ней.

## Проверить после правки

```sh
node tools/verify-package.cjs http://127.0.0.1:8786/
node tools/verify-home-kit.cjs http://127.0.0.1:8786/
node tools/verify-catalog-filters.cjs http://127.0.0.1:8786/
```

Проверка обслуживает **только эту папку** как HTTP-корень, проходит 9 ширин от 320 до 2560 px, переключение проектов/лотов, полные фильтры, разворот карты, форму заказа звонка, шрифты и изображения. Любые 404, ошибки JavaScript, внешние запросы для рендера и горизонтальное переполнение считаются ошибкой. Результат записывается в `verification/package.json`. Скрипт использует существующий Playwright из web-capture-toolkit; при другом расположении укажи `PLAYWRIGHT_PATH=/path/to/playwright`.

Вторая проверка сверяет роли общего UI-кита на 11 ширинах от 320 до 3840 px: поля контейнера, вертикальные отступы секций, брови и заголовки, типографику, кнопки, фильтр и форму. Отдельно она проверяет, что слой кита не меняет стили карточек. Её результат — `verification/home-kit-v1.json`.

Фильтры от 02.11.2026 используют композицию [курортного узла](https://github.com/daniilterekh-prog/barnes-sites/blob/main/main-site/pages/kurortnaya/filters-catalog-reference-2026-11-02.md): направление и «Покупка/Аренда» над строкой «Шоссе/Стоимость», четыре быстрых поля 2×2 на телефоне, поиск, выбранные условия и отдельные счётчик/карта/сортировка. Одна светлая полная форма открывается из hero, листинга и справа карты; спальни, сброс и остальные значения синхронизированы. Исходные загородные параметры, объекты и карточки сохранены. Реализация — `js/country-catalog-filters.js` и `css/country-catalog-filters.css`; отдельная устаревшая форма карты удалена. Проверка `verify-catalog-filters.cjs` проходит 8 ширин, поиск, dropdown, выбранные условия, полную форму, сброс и карту; результат — `verification/catalog-filters-2026-11-02.json`.

На 390 и 1440 px до и после упаковки проверено строгое полностраничное совпадение снимков: 0 отличающихся пикселей. Условия: Chrome, DPR 1, reduced motion, загруженные шрифты и ленивые изображения. Это не гарантия совпадения с внешним оригиналом во всех браузерах.

## Источники и ограничения

- Слой `css/home-kit-v1.css` реализует утверждённый [UI-кит главной v1.0.0 от 01.11.2026](https://github.com/daniilterekh-prog/barnes-sites/blob/main/main-site/pages/home/exact-2026-10-21/UI-KIT.md). Точные значения взяты из `source/home-spacing.css`, `source/home-typography.css` и `source/home-buttons.css` той же папки. Карточки сохраняют прежнее оформление: правила их адресов, фактов и заголовков из этого слоя убраны. Загородные изображения херо, композиция CTA, карта и поведение фильтров остаются собственными для этого узла. Новый слой подключён последним, без зависимости от соседних страниц.

- Каноническая библиотека BARNES — [barnes-assets](https://github.com/daniilterekh-prog/barnes-assets). Актуальный логотип взят из `brand/barn-estate/logo.svg` и сохранён локально как `assets/logo-canonical.svg`, чтобы страница не запрашивала его снаружи. Референс структуры узла — [`kurortnaya/`](https://github.com/daniilterekh-prog/barnes-sites/blob/main/main-site/pages/kurortnaya), но её файлы не требуются для рендера здесь.
- Херо desktop/mobile — два изображения, переданные пользователем 12.10.2026; фон CTA — утверждённый интерьер из курортного узла, теперь локальная копия. Локальный стиль хедера взят из шаблона `shared/owner-header.css` этого репозитория; фото плавающего эксперта — из `pictures/floating-expert/`. Tilda Sans скопирован из `assets/fonts/` репозитория.
- Слайдер — локальный [Splide 4.1.4](https://splidejs.com/), лицензия: `vendor/SPLIDE-LICENSE`. Другие frontend-пакеты не добавлялись. Бесплатные ресурсы сверены с [frontend-памяткой](https://github.com/daniilterekh-prog/codex-knowledge-base/blob/main/knowledge/frontend-playbook.md); утверждённый дизайн сохранён.
- Карта — локальный снимок с тайлами, не живой API Яндекс. Лоты и фильтры работают по сохранённым данным. Телефон, мессенджеры, политики, статьи и карточки объектов остаются внешними ссылками. Форма не подключена к backend; демонстрация окна не означает отправку заявки.
- Перечень удалённых устаревших файлов — `verification/cleanup.json`; восстановление возможно из истории Git. Библиотеку переносимых блоков, как в `kurortnaya/blocks/`, эта упаковка не создаёт: загородный узел хранит собственную целую страницу и данные.
