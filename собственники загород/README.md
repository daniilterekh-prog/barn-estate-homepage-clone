# Собственники — загород

Отдельная страница продажи загородной недвижимости BARN Estate. Создана из страницы «Собственникам — продажа» по поручению пользователя 12.11.2026; текущий опубликованный шаблон перенесён в изолированную копию без изменения основной продажи и пяти финальных узлов.

- [Открыть страницу](https://daniilterekh-prog.github.io/barn-estate-homepage-clone/собственники%20загород/)
- [ТЗ: собственник загородная, правки 11 ноября](https://docs.google.com/document/d/10h2UBtZCoKiUJGEKvC43um7Xax_V-sTJ3soDRDN-2iY/edit?tab=t.r3ubibduiehj)
- [Источники фото и происхождение файлов](COUNTRY-SOURCE.json)
- [Решения, границы и проверка](IMPLEMENTATION.md)

Вход — `index.html`. `country.css` и `country.js` содержат локальные исправления; `_site/` — только используемые замороженные зависимости действующего UI-кита. Изменяемые контроллеры эксперта находятся внутри этой папки, общие файлы сайта не меняются. Все необходимые визуальные ресурсы и шрифты локальные. Новые пакеты не устанавливались.

Локальный запуск: `python3 -m http.server 8000` из этой папки, затем `http://localhost:8000/`.

## Что сделано

Загородный первый экран и тексты; оригинальное новое фото Михаила Долгова из ТЗ в плавающей карточке и форме; более компактные вертикальные отступы; белый читаемый текст при наведении на бордовые карточки; явные рабочие адреса четырёх направлений и соответствующие изображения. Для зарубежного и коммерческого направлений подписи обозначают переход в соответствующий каталог. Региональные фотографии взяты из действующих страниц BARN Estate; точные пути и исходный commit сохранены в COUNTRY-SOURCE.json.

Основа оформления — существующий BARN Estate UI-kit, HTML/CSS/vanilla JavaScript. По frontend-памятке сохранён штатный стек; внешние компоненты, платные ресурсы и новые аккаунты не добавлялись. Оригинальное фото эксперта не ретушировалось, кадрирование выполнено CSS.

## Границы

GitHub Pages — статическое превью с `noindex, nofollow`. Заявки и подписка в превью не отправляются; интерфейс прямо сообщает об этом. Обработчик заявок/CRM и рабочий домен не подключались.

Фронт разработчиков `https://front.barnes.vsavr.ru/prodazha_zagorodnoy_nedvizhimosti/` при проверке 12.11.2026 возвращал HTTP 401. Доступа к CMS нет. Замечание ТЗ «фото из админки не подгружаются на фронт» нельзя исправить в статической копии: интеграция CMS остаётся задачей разработчиков, не отмечена выполненной.
