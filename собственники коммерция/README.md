## Что сделано

Первый экран продажи коммерческого объекта, шесть преимуществ, одиннадцать инструментов продвижения, шесть этапов, стратегия и шесть вопросов FAQ. В плавающей карточке, форме и CTA — подлинное изображение Алины Медведевой. CTA описывает оценку, продвижение и продажу объекта. Уточнены интервалы секций, контраст бордовых карточек, клавиатурная навигация и валидация.

Три другие услуги: городская продажа в Москве, загородная продажа и аренда. Изображения `service-city.webp`, `service-country.webp`, `service-rent.webp` побайтно взяты из общего узла `sobstvenniki-uzel/assets/editorial/`.

Десять новых отдельных иллюстраций: первый экран, шесть карточек, стратегия, панорама и рассылка. Сцены иллюстративные, не фотографии конкретных лотов. Портрет эксперта и логотипы не генерировались.

## Файлы и запуск

`index.html` — полная страница; `CONTENT.json` — редакционное наполнение; `owner-sale.js` — локальный контроллер; `commercial.css/js` — изолированные дополнения; `_site/` — замороженные зависимости страницы. Общие файлы и пять финальных узлов не меняются. HTML/CSS/vanilla JavaScript; новых библиотек и аккаунтов нет.

Из этой папки: `python3 -m http.server 8796`, затем `http://localhost:8796/`.
